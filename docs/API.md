## Built-in functions

Part of the language itself: printing, stopping with an error, and a few functions the compiler knows.

```gdscript
# example: built-in functions
print("hello", 42, 3.5, [1, 2, 3])      # any values, separated by spaces
xs = fill(0, 5)                          # five zeros
xs[2] = 7
assert(xs.len() == 5, "five of them")   # stops the program if not true
print(xs, sqrt(2.0), size_of(int))
b = bytes("hi")                          # a string's bytes, as u8[]
print(b, str_from_bytes(b))
if xs[2] != 7: panic("xs[2] changed")   # stop, with a message and where it happened
```

- `print(values...)`: prints the values, separated by spaces, and a line break
- `assert(ok: bool, message: str = "")`: stops the program (with the message, and where) if `ok` is false
- `panic(message: str)`: stops the program, with the message and where each function on the way was called
- `fill[T](x: T, n: int) -> T[]`: an array of `n` copies of `x`
- `sqrt(x: f64) -> f64`: the square root
- `sqrt(x: f32) -> f32`
- `embed(path: str) -> u8[]`: a file's contents, read when the program is compiled and kept in it (the path is relative to the source file)
- `bytes(s: str) -> u8[]`: a string's bytes (UTF-8)
- `str_from_bytes(b: u8[]) -> str`: a string of these bytes
- `size_of(T) -> int`: how many bytes a value of type T takes, and its alignment
- `align_of(T) -> int`
- `int(x)`: a number as another type (float to integer truncates toward zero), or any value as text, as `print` shows it
- `f64(x)`
- `f32(x)`
- `u8(x)`
- `str(x)`

## Arrays

`T[]` is a growable array. Arrays are values: assigning one or passing it to a function gives a copy (shared until one of them changes). Functions can be called as `f(xs, y)` or `xs.f(y)`.

```gdscript
# example: arrays
scores = [12, 40, 7, 33]
scores.push(25)                          # add at the end
scores.sort()
print(scores)                            # [7, 12, 25, 33, 40]
print(scores.len(), scores.first(), scores.last(), scores.sum())

big = scores.filter((s): s > 20)         # a new array: [25, 33, 40]
print(big.map((s): s * 2))
print(scores.any((s): s > 35), scores.count((s): s % 2 == 1))

loop i in 0.. and s in scores:           # an index and the elements together
    print("{i}: {s}")

top = scores.pop()                       # take the last one off
scores.insert(0, 1)                      # put one in at the front
print(top, scores, scores.contains(12), scores.index_of(25))
```

#### Built in

- `len(xs: T[]) -> int`: how many elements
- `push(xs: mut T[], x: T)`: adds `x` at the end
- `pop(xs: mut T[]) -> T`: removes the last element and gives it back
- `insert(xs: mut T[], i: int, x: T)`: puts `x` in at index `i`, moving the ones after it along
- `remove(xs: mut T[], i: int) -> T`: takes out the element at `i` and gives it back
- `extend(xs: mut T[], ys: T[])`: adds all of `ys` at the end
- `clear(xs: mut T[])`: removes every element
- `truncate(xs: mut T[], n: int)`: keeps the first `n` elements
- `resize(xs: mut T[], n: int)`: makes it `n` long: new elements are zero
- `reserve(xs: mut T[], n: int)`: makes room for `n` elements without growing again; `cap` is the room there is
- `cap(xs: T[]) -> int`

## Strings

`str` is text, in UTF-8. `"{x}"` puts a value in a string; `"{x:.2}"` rounds it to two decimals (more ways: [the language](LANGUAGE.md#2-lexical-structure)). Strings are values, like arrays.

```gdscript
# example: strings
name = "  Sloppy  ".trim()
print(name.upper(), name.len(), name.starts_with("Slo"))

words = "the quick brown fox".split(" ")
print(words, words.join("-"))

# {...} puts a value in a string; after a colon, how to show it
pi = 3.14159
print("pi is about {pi:.2}, a million is {1000000:,}, a quarter is {0.25:.0%}")
print("[{name:<10}] [{name:>10}] [{7:03}]")

n = to_int("42") ?? 0                    # none if it is not a number: 0 instead
print(n + 1, "ab" * 3, "a,b,c".replace(",", "; "))
print("héllo".len(), "héllo".char_count())   # bytes (UTF-8), and characters
```

String utilities. Strings are immutable UTF-8 byte sequences; indexing gives bytes.

- `find = (s: str, sub: str, start: int = 0) -> int`

## Maps

`{K: V}` maps keys to values, in the order they were added.

```gdscript
# example: maps
ages = {"ada": 36, "alan": 41}
ages["grace"] = 85                       # add or change
print(ages["ada"], ages.len(), ages.has("bob"))
print(ages.get("bob") ?? 0)              # none for a missing key: 0 instead

counts: {str: int} = {}
loop w in "a rose is a rose is a rose".split(" "):
    counts[w] += 1                       # a missing key starts at 0
loop word, n in counts:                  # in the order they were added
    print("{word}: {n}")
counts.remove("is")
print(counts.keys(), counts.values())
```

Hash map {K: V}: insertion ordered, open addressing over a dense entry list. The first two fields must stay `keys` and `vals` (the compiler iterates them in for loops).

- `struct Map[K, V]`
- `hash = (x: int) -> u64`: full 64-bit avalanche (murmur3 finalizer): every key bit affects the low bits used for slots, so keys like multiples of 4096 or float bit patterns spread out
- `hash = (x: u64) -> u64`
- `hash = (x: bool) -> u64`
- `hash = (x)`
- `([]=)[K, V] = (m: mut Map[K, V], k: K, v: V)`
- `([])[K, V] = (m: Map[K, V], k: K) -> V`
- `get[K, V] = (m: Map[K, V], k: K) -> V?`
- `get[K, V] = (m: Map[K, V], k: K, default: V) -> V`
- `contains[K, V] = (m: Map[K, V], k: K) -> bool`
- `has[K, V] = (m: Map[K, V], k: K) -> bool`
- `len[K, V] = (m: Map[K, V]) -> int`
- `is_empty[K, V] = (m: Map[K, V]) -> bool`
- `keys[K, V] = (m: Map[K, V]) -> K[]`
- `values[K, V] = (m: Map[K, V]) -> V[]`
- `clear[K, V] = (m: mut Map[K, V])`
- `remove[K, V] = (m: mut Map[K, V], k: K) -> bool`: remove a key; returns true if it was present. The entries after it move up (the rest keep their order).

## Files, time and the system

In a web page, files are the ones the page was given, and `env` reads its address's parameters.

```gdscript
# example: files, time and the system
start = time()
write_file("notes.txt", "first line\nsecond line\n")
if let text = read_file("notes.txt"):    # none if it could not be read
    loop line in text.lines(): print("> {line}")
print(file_exists("notes.txt"), args())
delete_file("notes.txt")
home = env("HOME") ?? "(no HOME)"
print(home, cpu_count())
print("took {(time() - start) * 1000.0:.2} ms")
```

- `exit = (code: int)`

- `read_file = (path: str) -> str?`: read a whole file; none if it cannot be read
- `read_bytes = (path: str) -> u8[]?`
- `write_file = (path: str, contents: str) -> bool`

- `file_exists = (path: str) -> bool`

- `delete_file = (path: str) -> bool`
- `time = () -> f64`: seconds since an arbitrary point (monotonic clock)

- `write = (s: str)`: print without a trailing newline

## JSON and base64

```gdscript
# example: JSON and base64
text = r"""{"name": "slime", "hp": 12, "drops": ["gel", "coin"]}"""   # (r: no {...} in it)
r = parse_json(text)
if r is JsonError:
    print("not JSON: {r.message}")
else:
    j: Json? = r
    print(j.get("name").as_str() ?? "?", j.get("hp").as_int() ?? 0)
    print(j.get("drops").at(1).as_str() ?? "?")
    print(to_json(r))

code = base64_encode(bytes("hello"))
print(code, str_from_bytes(base64_decode(code) ?? []))
```

### json.jo

JSON: parse_json reads text into a Json value (or a JsonError saying where it is wrong), and to_json writes one. Reading: get (a field), at (an element) and the as_* functions all take a Json? and give an optional, so they chain, and a missing piece anywhere gives none:

```gdscript
j = parse_json(text)
if j is JsonError: return j
width = j.get("width").as_int() ?? 0
name = j.get("layers").at(0).get("name").as_str() ?? "?"
loop l in j.get("layers").as_list(): print(l.get("name").as_str() ?? "")
```

- `enum Json: null_, boolean(b: bool), number(n: f64), text(s: str), list(items: Json[]), object(keys: str[], values: Json[])`
- `struct JsonError`
- `parse_json = (s: str) -> Json \| JsonError`

#### Reading

- `get = (j: Json?, key: str) -> Json?`: an object's field
- `at = (j: Json?, i: int) -> Json?`: a list's element
- `as_num = (j: Json?) -> f64?`
- `as_int = (j: Json?) -> int?`
- `as_str = (j: Json?) -> str?`
- `as_bool = (j: Json?) -> bool?`
- `as_list = (j: Json?) -> Json[]`: a list's elements (none: an empty array)
- `keys = (j: Json?) -> str[]`: an object's field names, in order
- `is_null = (j: Json?) -> bool`

#### Writing

- `to_json = (j: Json, indent: int = 0) -> str`: JSON text for a value (indent > 0: on several lines, indented by that many spaces)

### base64.jo

Base64: bytes as text (A-Z a-z 0-9 + /, padded with =), and back.

- `base64_encode = (b: u8[]) -> str`
- `base64_decode = (s: str) -> u8[]?`: the bytes, or none if s is not base64 (spaces and line breaks in it are skipped)

## Saving

```gdscript
# example: saving
# (a place of the program's own: a folder for the user on the desktop, the page's storage on the web)
runs = to_int(load_data("runs") ?? "0") ?? 0
runs += 1
save_data("runs", "{runs}")
print("runs so far: {runs}")
```

Data a program keeps between runs: saved games, settings, high scores.

```gdscript
save_data("progress", "{level}\n{coins}")
if let s = load_data("progress"): ...
```

Each program has its own place, named after it (PROGRAM_NAME: the build block's `name`, else the main file's name): on Linux ~/.local/share/<name>/ (or $XDG_DATA_HOME), on Windows %APPDATA%\<name>\, on macOS ~/Library/Application Support/<name>/, in a web page the browser's storage for the page (it survives reloads and restarts of the browser). SLOPPY_SAVE_DIR puts it somewhere else (tests).

- `save_dir = () -> str`: the directory a program's data goes to (made when first written; "" in a web page)
- `save_data = (name: str, contents: str) -> bool`: keep contents under name (a file name: no / or \); false if it could not be written
- `load_data = (name: str) -> str?`: what was kept under name; none if nothing was

## Threads

```gdscript
# example: threads
slow_square = (n: int) -> int:
    total = 0
    loop i in [0..n): total += n
    total

nums = [loop i in [0..16): 1000000 + i]
squares = parallel_map(nums, slow_square)      # spread over every core
print(cpu_count(), "cores", squares[0], squares[15])

halves = parallel_range(8, (i): f64(i) / 2.0)  # f(0) .. f(7), in parallel
print(halves)
```

Data parallelism on a pool of worker threads (fork-join).

```gdscript
squares = parallel_map(nums, (x): x * x)
parallel_update(particles, (p): step(p, dt))      # xs[i] = f(xs[i]), in place
rows = parallel_range(height, (y): render_row(y))
```

The function runs on several threads at once: it may read anything, but it must not change globals or the variables it captured (that would be a data race); return results instead. On the web target everything runs on the calling thread.

- `cpu_count = () -> int`: number of hardware threads available to this process
- `parallel_map[T, U] = (xs: T[], f: (T) -> U) -> U[]`
- `parallel_update[T] = (xs: mut T[], f: (T) -> T)`
- `parallel_range[U] = (n: int, f: (int) -> U) -> U[]`

## Numeric arrays

Elementwise operators (`.+ .* .^`...), `f.(xs)` and n-dimensional arrays are part of the language: see [arrays for numeric work](LANGUAGE.md#8-arrays-for-numeric-work). These are the functions on them.

```gdscript
# example: numeric arrays
xs = linspace(0.0, 1.0, 5)               # [0.0 0.25 0.5 0.75 1.0]
ys = 3.0 .* xs .^ 2.0 .+ 1.0             # element by element, as one loop
print(ys, sqrt.(xs), xs .> 0.5)
print(mean(ys), dot(xs, ys))

m = [1.0 2.0; 3.0 4.0]                   # a 2 x 2 matrix
print(m.shape, m[1, 0], m * [1.0, 1.0], m * transpose(m))
grid = zeros(3, 4)
grid[1, 2] = 5.0
print(grid)
```

Arrays for numeric work, in the spirit of numpy and MATLAB.

T[,] is an n-dimensional array (NDArray[T]): its elements in row-major order, and its shape. How many dimensions it has is part of the value, as in numpy (T[,,] is the same type; the commas are only for the reader). Write a 2-D one as [1 2; 3 4] (rows separated by ';' or line breaks), stack arrays with [a; b], or make one with zeros(2, 3, 4), ones, eye, rand, reshape. m[i, j] (with as many indexes as dimensions) reads and writes an element; m.shape is its shape. Ranges select parts: m[i, ..] is row i, m[.., j] column j, m[1..2, 0..] a block (ranges include both ends; missing indexes at the end mean whole axes). A part is an array of its own; assigning to one (m[.., 0] = xs, m[0, ..] = 0.0) writes into m.

The dotted operators work element by element on arrays of any shape, and broadcast like numpy (a dimension of length 1, or a missing leading one, stretches to fit): a .* b, m .+ 1.0, v .^ 2, xs .< 0.5, and f.(xs) applies f to each element. A whole dotted expression runs as one loop. On 2-D arrays the plain operators follow linear algebra: a * b is the matrix product.

## The window, the game loop and input

A program that defines `update(dt: f64)` or `draw()` opens a window and calls them every frame. More on windows, screen sizes and the game loop: [the language](LANGUAGE.md#12-programs-and-the-game-loop).

```gdscript
# example: the window, the game loop and input
window("Input", 960, 540)               # the title, and the size of the 2D area

pos = vec2(480, 270)
trail: vec2[] = []

update = (dt: f64):                      # every frame; dt: the seconds since the last one
    pos += input_axis() * f32(320 * dt)  # arrows, W A S D, or a gamepad's stick
    if mouse_down(.left): pos = mouse_pos()
    if key_pressed(.space): trail.clear()
    if key_pressed(.f): toggle_fullscreen()
    if key_pressed(.tab): show_stats(not stats_shown())     # frame times, and the zones' below
    zone("trail")                         # a part of the frame, timed in the statistics
    trail.push(pos)
    if trail.len() > 60: trail.remove(0)
    zone_end()

draw = ():                               # every frame, after update
    clear(rgb(0.08, 0.09, 0.12))
    loop i in 0.. and p in trail: circle(p, 4, rgba(0.3, 0.7, 0.9, f64(i) / 60.0))
    circle(pos, 18, ORANGE)
    text("move: arrows, W A S D or click   space: clear   F: fullscreen   Tab: statistics", vec2(20, 20), 20)
    text("{fps():.0} fps, {elapsed():.1} s", vec2(20, 500), 18, GRAY)
```

## Controls and gamepads

```gdscript
# example: controls and gamepads
window("Controls", 960, 540)

# actions with their default keys and buttons; the player can change them (ui_controls)
action("jump", [.key(.space), .key(.w), .button(.a)])
action("left", [.key(.a), .key(.left), .stick(0, -1), .button(.left)])
action("right", [.key(.d), .key(.right), .stick(0, 1), .button(.right)])

x = 480.0
y = 0.0
vy = 0.0
settings = false

update = (dt: f64):
    if key_pressed(.tab): settings = not settings
    if settings: return
    x += action_axis("left", "right") * 300 * dt        # -1 to 1 (a stick gives in between)
    if action_pressed("jump") and y == 0.0: vy = 500.0
    vy -= 1200 * dt
    y = max(0.0, y + vy * dt)

draw = ():
    clear(rgb(0.1, 0.1, 0.14))
    rect(0, 440, 960, 100, rgb(0.25, 0.3, 0.25))
    rect(x - 20, 400 - y, 40, 40, ORANGE)
    text("move: A D or arrows   jump: space or W   Tab: change the controls   ({gamepads().len()} gamepads)", vec2(20, 20), 20)
    if settings:
        ui_begin("controls", vec2(480, 100))
        ui_controls()                    # choose an action, then press its new key or button
        if ui_button("Back") or ui_back(): settings = false
        ui_end()
```

### controls.jo

Controls the player can change. The game names its actions and gives each its default inputs, then asks for actions, never for keys; ui_controls() is a settings screen where the player rebinds them (choose one, press the new key or button), and the bindings are saved.

```gdscript
action("jump", [.key(.space), .button(.a)])
action("left", [.key(.a), .key(.left), .stick(0, -1), .button(.left)])
action("right", [.key(.d), .key(.right), .stick(0, 1), .button(.right)])
...
if action_pressed("jump"): jump()

# in the settings menu:
ui_begin("settings", vec2(640, 140))
ui_controls()
if ui_button("Back") or ui_back(): ...
ui_end()
```

- `enum Input: key(k: Key), button(b: PadButton), mouse(m: Mouse), stick(axis: int, dir: int)`: an input: a key, a gamepad button, a mouse button, or a stick or trigger pushed one way (axis: 0 left x, 1 left y, 2 right x, 3 right y, 4 left trigger, 5 right trigger; dir: 1 or -1)

- `action_value = (name: str, player: int = -1) -> f64`: how far the action is pushed, 0 to 1 (the most of its inputs)
- `action_down = (name: str, player: int = -1) -> bool`
- `action_pressed = (name: str, player: int = -1) -> bool`: true in the frame the action was pressed (a stick: when it goes past halfway)
- `action_released = (name: str, player: int = -1) -> bool`
- `action_axis = (neg: str, pos: str, player: int = -1) -> f64`: from -1 (neg) to 1 (pos): action_axis("left", "right")

#### Bindings

- `bindings = (name: str) -> Input[]`
- `set_bindings = (name: str, inputs: Input[])`
- `reset_controls = ()`: every action back to its defaults
- `input_name = (x: Input) -> str`: what an input is called, for showing it ("Space", "Pad A", "Left stick right")

#### Rebinding

- `input_pressed = () -> Input?`: the input the player pressed first this frame (a key, a button, a click, a stick pushed most of the way), if any

### gamepad.jo

### screen.jo

How a game's picture fits windows of any size and shape.

A game is drawn in 2D units: the size given to window() (its design size), so the same coordinates work in any window. Two settings decide how that maps to the window's pixels:

```gdscript
screen_fit(mode): what a window of another shape shows
    .expand     the design area, scaled to fit, and more around it (the default: no bars,
                nothing cut; visible_rect() says what is shown)
    .letterbox  just the design area, scaled to fit, with bars (letterbox_color) around it
    .crop       the design area scaled to fill the window: what does not fit is cut off
    .stretch    the design area stretched to the window (shapes distort)
    .native     no scaling: one 2D unit is one pixel of the window (screen_size() is its size)

render_resolution(w, h): draw at a fixed resolution, scaled up to the window, by default
    with sharp pixels (nearest) and in whole steps (2x, 3x...); 2D units stay the design size
    (give both the same shape). The picture letterboxes (or crops/stretches with those
    fits). render_resolution(0, 0) goes back to the window's resolution.
pixel_art(): render_resolution at the design size: for a game designed at 320 x 180, one
    2D unit is one sharp pixel. (A window for a design that small opens a whole number of
    times larger.)
render_scale(s): draw at a fraction of the window's pixels (0.5: a quarter of them), scaled
    up smoothly: faster where pixels cost (3D, the software renderer).
```

Drawing that needs it goes to an offscreen canvas, put on the window when the frame ends; the mouse is mapped back the same way (mouse_pos() is in 2D units).

### tilemap.jo

Tilemaps: layers of tiles drawn from a tileset image. Make one from text (tile_layer: each character is a tile), or load a map made in Tiled (load_tiled: a .tmj/.json map). Draw it with draw_tilemap, and move boxes through it with tilemap_move, which stops them at solid tiles. Every tile is solid unless set_tile_shape says otherwise: a one-way platform (landed on from above, passed through from below and the sides), a slope (a floor that rises or falls across the tile), or empty (scenery).

```gdscript
tiles = tileset(load_texture(embed("tiles.png"), false), 16, 16)
level = tilemap(tiles, [tile_layer("walls", WALLS, "#=")])     # '#': tile 1, '=': tile 2
update = (dt: f64):
    m = tilemap_move(level, 0, box, vel * f32(dt))
    box = m.rect
    if m.hit_y: vel.y = 0.0
draw = (): draw_tilemap(level)
```

- `struct Tileset`
- `struct TileLayer`
- `struct MapObject`: an object placed in Tiled (an object layer's): a spawn point, a door, a coin...
- `enum TileShape:`: how a tile stops what moves through the map (tilemap_move): solid; empty (scenery); platform (one-way: landed on from above, passed through from below and the sides); slope(left, right), a floor whose height (0: the tile's bottom, 1: its top) goes from left at the tile's left side to right at its right side: slope(0, 1) rises to the right, slope(0, 0.5) then slope(0.5, 1) gently over two tiles (passed through from below)
- `struct Tilemap`
- `struct TileMove`
- `tileset = (t: Texture, tile_w: int, tile_h: int, spacing: int = 0, margin: int = 0) -> Tileset`: a tileset: an image of equal tiles in a grid, numbered from `first` (1) left to right, then down
- `tile_layer = (name: str, rows: str, chars: str) -> TileLayer`: a layer from rows of text: the character at position i of `chars` is tile i + 1, and any other character (a space, a dot) is no tile; a character the rows never use skips a number ("_#": '#' is tile 2). Blank lines at the start and the end are left out.
- `tilemap = (ts: Tileset, layers: TileLayer[]) -> Tilemap`: a map of these layers, drawn with one tileset
- `layer_index = (m: Tilemap, name: str) -> int`: the index of the layer with this name (-1: none)
- `tile_at = (m: Tilemap, layer: int, x: int, y: int) -> int`: the tile at column x, row y of a layer (0 outside the map)
- `tile_at = (m: Tilemap, layer: int, p: vec2) -> int`: the tile under a point (in pixels)
- `set_tile = (m: mut Tilemap, layer: int, x: int, y: int, id: int)`
- `set_tile_shape = (m: mut Tilemap, id: int, shape: TileShape)`: how tile id stops what moves (every tile is solid until this says otherwise)
- `tile_shape = (m: Tilemap, id: int) -> TileShape`
- `tilemap_size = (m: Tilemap) -> vec2`: the map's size in pixels
- `draw_tilemap = (m: Tilemap, layer: int = -1, at: vec2 = vec2(0, 0), tint: vec4 = vec4(1, 1, 1, 1))`: draw a layer (-1: every visible layer, bottom first), with the map's top left corner at `at`. Only the tiles on the screen are drawn, wherever the camera is.
- `tilemap_hits = (m: Tilemap, layer: int, r: Rect) -> bool`: does a box (in pixels) touch a tile of the layer?
- `tilemap_move = (m: Tilemap, layer: int, r: Rect, d: vec2, drop: bool = false) -> TileMove`: move a box by d, stopping it against the layer's tiles: sideways first, then up or down, so it slides along walls and floors. However far it moves in one step, it does not pass through a solid tile. Platforms stop it only coming down onto them (drop: not even then, to drop through one); on a slope it walks up and down the slope's floor, staying on it going down.

#### Tiled

- `load_tiled = (json: str, textures: Texture[]) -> Tilemap \| JsonError`: a map saved by Tiled as JSON (.tmj), with its tilesets embedded in it (Tiled: in the Tilesets view, "Embed Tileset"), and a texture for each tileset, in the map's order. Tile layers (also inside groups) become layers, object layers become `objects`. Layer data can be plain, or base64 (uncompressed, zlib or gzip).

## Models (glTF)

3D models from glTF 2.0 files (.glb, or .gltf with its .bin and images), the format Blender and most tools export: meshes, with their materials' base color (a factor and a texture, PNG or JPEG), vertex colors and emissive light, placed by the scene's nodes; skins (meshes bent by a skeleton of nodes, up to 64 joints) and their animations.

```gdscript

```

An animated model is drawn in a pose: an animation at a time, or two blended.

```gdscript
run = find_animation(hero, "Run")
```

- `struct Model`

### vorbis.jo

## GPU programs

```gdscript
# example: GPU programs
window("Shader", 960, 540)

struct Vertex:
    pos: vec2
struct Params:
    time: f32
    size: vec2
struct Out:
    pos: vec4                            # (the first field: where on the screen)
    uv: vec2

vs = (v: Vertex, u: Params) -> Out: Out(vec4(v.pos, 0, 1), v.pos * 0.5 + 0.5)
fs = (i: Out, u: Params) -> vec4:        # runs for every pixel, on the GPU
    p = (i.uv - 0.5) * vec2(u.size.x / u.size.y, 1.0)
    d = length(p)
    rgb(0.5 + 0.5 * sinf(d * 30.0 - u.time * 4.0), 0.3, 0.6 + 0.4 * cosf(u.time + p.x * 3.0))

prog = make_shader(shader(vs, fs))
quad = mesh([Vertex(vec2(-1, -1)), Vertex(vec2(1, -1)), Vertex(vec2(1, 1)),
             Vertex(vec2(-1, -1)), Vertex(vec2(1, 1)), Vertex(vec2(-1, 1))])
t = 0.0
update = (dt: f64): t += dt
draw = (): draw(prog, quad, Params(f32(t), vec2(960, 540)))
```

GPU programs written in Sloppy: meshes, shaders and uniform binding.

```gdscript
struct Vertex: pos: vec3; color: vec4          -> vertex attributes
struct Params: mvp: mat4                        -> uniforms
struct Out:    pos: vec4; color: vec4           -> first field is the clip position
vs = (v: Vertex, u: Params) -> Out: Out(u.mvp * vec4(v.pos, 1), v.color)
fs = (i: Out, u: Params) -> vec4: i.color
prog = make_shader(shader(vs, fs))
m = mesh(vertices)
draw(prog, m, Params(mvp))
```

Uniform fields are numbers, vectors, mat4 and Texture, or fixed-size arrays of them (`bones: mat4[64]`, `lights: vec4[8]`), and GPU buffers (gpubuffer.jo: `u.particles[i]`). Shader code can use fixed-size arrays, `loop` over them, and sample(), sample_lod(), texel(), texture_size(), discard() (fragment) and vertex_id(), instance_id() (vertex).

- `struct ShaderSource`: produced by the compiler from shader(vs, fs)
- `struct ShaderAttrib`
- `struct ShaderUniform`
- `struct Shader`
- `struct Mesh`
- `make_shader = (src: ShaderSource) -> Shader`
- `mesh[V] = (vertices: V[], indices: u32[] = [], mode: int = GL_TRIANGLES) -> Mesh`: upload vertices (any struct type matching the shader's vertex input) and optional indices
- `update_mesh[V] = (m: mut Mesh, vertices: V[])`
- `draw[U] = (sh: Shader, m0: Mesh, params: U)`: draw a mesh with a shader; `params` is the uniforms struct the shader functions take
- `draw_instanced[U, I] = (sh: Shader, m: mut Mesh, instances: I[], params: U)`: draw many copies of a mesh in one call; `instances` holds the per-instance shader input (uploaded on every call: for instances that change rarely, keep them on the GPU with instance_buffer)
- `struct InstanceBuffer[I]`: per-instance shader input kept on the GPU: uploaded once (and again by set_instances), drawn any number of times with draw_instanced
- `instance_buffer[I] = (instances: I[]) -> InstanceBuffer[I]`
- `set_instances[I] = (b: mut InstanceBuffer[I], instances: I[])`: replace what an instance buffer holds
- `draw_instanced[U, I] = (sh: Shader, m: Mesh, b: InstanceBuffer[I], params: U, first: int = 0, count: int = -1)`: draw instances first .. first + count of a buffer (count -1: to the end)
- `sample = (t: Texture, uv: vec2) -> vec4`: texture lookup inside shader functions (maps to GLSL texture()); outside the software renderer, calling it on the CPU returns white
- `sample_lod = (t: Texture, uv: vec2, lod: f32) -> vec4`: texture lookup at a given mipmap level (maps to GLSL textureLod; the software renderer has no mipmaps and samples the full-size image)
- `texel = (t: Texture, p: ivec2) -> vec4`: the texel at integer coordinates p (0 to size - 1; y = 0 is the first row of the image data): no filtering or wrapping (maps to GLSL texelFetch)
- `texture_size = (t: Texture) -> ivec2`: a texture's size in texels (maps to GLSL textureSize)
- `discard = ()`: in a fragment shader: drop this fragment (no color, no depth), e.g. for alpha-tested leaves: `if c.a < 0.5: discard()`. The rest of the function still runs on the CPU; its result is unused.
- `vertex_id = () -> int`: in a vertex shader: the index of the vertex being shaded (GLSL gl_VertexID) and of the instance (gl_InstanceID: 0 for draw, the index into the instances for draw_instanced)
- `instance_id = () -> int`
- `fwidth = (x: f32) -> f32`: in a fragment shader: how much x changes from one pixel to the next (GLSL fwidth), e.g. for edges that stay sharp at any size; 0 on the CPU
- `fract = (v: vec2) -> vec2`
- `step = (edge: f32, x: f32) -> f32`

## GPU arrays

```gdscript
# example: GPU arrays
xs = gpu(linspace(0.0, 1.0, 1000000))    # a million numbers, on the GPU
ys = xs .* xs .+ 1.0                     # one GPU program, run on all of them
print(gpu_available(), sum(ys), mean(ys), max(ys))
print(cpu(ys).data[999999])              # back on the CPU
```

GPU arrays: numbers kept in GPU memory and computed on by GPU programs.

```gdscript
g = gpu(xs)                       # upload (up to 4 dimensions)
h = g .* 2.0 .+ sin.(g)           # one GPU program, made from the expression at compile time
ys = cpu(h)                       # download: an array of the same shape
total = sum(h)                    # reductions too
```

Values are f32, or i32 for arrays made from integers (gpu(int_array)): integer arithmetic keeps integer semantics (7 / 2 is 3), and mixing with floats gives floats. A dotted expression whose arrays are GPU arrays runs on the GPU as one program (the functions applied with f.(g) are translated like shader functions; numbers in the expression become its parameters). Shapes broadcast as on the CPU. Native programs use Vulkan where they can: an array is a buffer, the program a compute program (compiler/spirv.jo, spirv_kernel), with or without a window. Otherwise they use OpenGL ES (without a window, through a windowless EGL context), and web builds WebGL 2: an array is a float texture holding four values per texel, the program a fragment program drawn over it. Where none of these can (no driver, SLOPPY_SOFTWARE=1, an old browser, node) the same expressions run on the CPU, so programs work everywhere; gpu_available() tells which.

- `struct GpuArray[T]`
- `gpu_available = () -> bool`

#### Moving data

- `gpu = (xs: f32[]) -> GpuArray[f32]`
- `gpu = (xs: f64[]) -> GpuArray[f32]`
- `gpu = (xs: i32[]) -> GpuArray[i32]`
- `gpu = (xs: int[]) -> GpuArray[i32]`
- `gpu = (xs: bool[]) -> GpuArray[f32]`
- `gpu = (m: NDArray[f32]) -> GpuArray[f32]`
- `gpu = (m: NDArray[f64]) -> GpuArray[f32]`
- `gpu = (m: NDArray[i32]) -> GpuArray[i32]`
- `gpu = (m: NDArray[int]) -> GpuArray[i32]`
- `cpu[T] = (g: GpuArray[T]) -> NDArray[T]`: the values (an array of the GPU array's shape)
- `len[T] = (g: GpuArray[T]) -> int`

#### Reductions

- `sum = (g: GpuArray[f32]) -> f64`: Floats are reduced on the GPU (64 values at a time, until few are left), then added up in f64; integers are added up exactly, in 64 bits, on the CPU (their min and max are found on the GPU with Vulkan).
- `sum = (g: GpuArray[i32]) -> int`
- `mean = (g: GpuArray[f32]) -> f64`

## GPU buffers and compute

For programs that keep their data on the GPU: buffers of any struct, functions run once per element (`compute`, `dispatch`) and draws the GPU decides (`draw_indirect`). Through Vulkan these run on the GPU; elsewhere on the CPU, so programs work everywhere.

```gdscript
# example: GPU buffers and compute
window("Swarm", 960, 540)

struct Bug:
    pos: vec2
    vel: vec2
struct Step:
    bugs: GpuBuffer[Bug]
    dt: f32
    time: f32

# runs on the GPU, once for each bug
step = (id: int, u: Step):
    b = u.bugs[id]
    a = f32(id) * 0.000314 + u.time * 0.3
    r = 0.45 + 0.3 * sinf(a * 5.0 + u.time)
    goal = vec2(cosf(a) * r * 0.5625, sinf(a) * r)
    b.vel = b.vel * 0.94 + (goal - b.pos) * u.dt * 12.0
    b.pos += b.vel * u.dt
    u.bugs[id] = b

struct Corner:
    at: vec2
struct Look:
    bugs: GpuBuffer[Bug]
struct Out:
    pos: vec4
    color: vec4

vs = (c: Corner, u: Look) -> Out:
    b = u.bugs[instance_id()]
    Out(vec4(b.pos + c.at * vec2(0.004, 0.007), 0, 1), vec4(0.3 + length(b.vel) * 3.0, 0.7, 1.0 - length(b.vel) * 2.0, 1))
fs = (i: Out, u: Look) -> vec4: i.color

bugs = gpu_buffer([loop i in [0..20000): Bug(vec2(sinf(f32(i)), cosf(f32(i) * 1.7)) * 0.9, vec2(0, 0))])
stepper = compute(step)
prog = make_shader(shader(vs, fs))
quad = mesh([Corner(vec2(-1, -1)), Corner(vec2(1, -1)), Corner(vec2(0, 1))])
t = 0.0
update = (dt: f64):
    t += dt
    dispatch(stepper, len(bugs), Step(bugs, f32(dt), f32(t)))
draw = ():
    clear(rgb(0.05, 0.06, 0.1))
    draw_instanced(prog, quad, len(bugs), Look(bugs))
```

GPU buffers and compute programs: arrays kept in GPU memory, and functions written in Sloppy that run on the GPU once per element.

```gdscript
struct Particle: pos: vec2; vel: vec2
struct Step: parts: GpuBuffer[Particle]; dt: f32
step = (id: int, u: Step):                    # a compute function: (id, parameters)
    p = u.parts[id]
    p.pos += p.vel * u.dt
    u.parts[id] = p
parts = gpu_buffer(particles)                 # upload (gpu_buffer[Particle](n): n zeros)
stepper = compute(step)                       # the program (the compiler makes it)
dispatch(stepper, len(parts), Step(parts, dt))    # step(id, ...) for each id in [0, len(parts))
ps = cpu(parts)                               # download
```

A compute function over a grid takes id: ivec2 (dispatch(k, ivec2(w, h), params)).

Shaders read buffers among their uniforms (`u.parts[instance_id()]`); a buffer can also be a mesh's vertices (gpu_mesh), a draw's instances (draw_instanced) and the counts of draws the GPU decides (draw_indirect with DrawArgs; draw_indirect_count: how many draws, too). Only compute functions write buffers; atomic_add() and the others change an element of a GpuBuffer[i32] or GpuBuffer[u32] that many invocations change at once. What a dispatch writes is seen by every dispatch and draw after it.

Through Vulkan a buffer is GPU memory read by its address and a compute function a compute program (compiler/spirv.jo); elements are laid out as the CPU lays them out. Elsewhere (OpenGL, the software renderer, the web) buffers are in CPU memory and compute functions run on the CPU, on every core; shaders read buffers through a copy in an integer texture. So programs run everywhere: gpu_compute() tells which way.

- `struct GpuBuffer[T]`
- `gpu_compute = () -> bool`: whether buffers are in GPU memory and compute functions run on the GPU (Vulkan: the window's, or one with no window), or else in CPU memory and on the CPU

#### Making, reading and writing buffers

- `gpu_buffer[T] = (n: int) -> GpuBuffer[T]`
- `gpu_buffer[T] = (xs: T[]) -> GpuBuffer[T]`
- `len[T] = (b: GpuBuffer[T]) -> int`
- `cpu[T] = (b: GpuBuffer[T]) -> T[]`: all the elements, or count of them from first (after what the GPU was given to do has run)
- `cpu[T] = (b: GpuBuffer[T], first: int, count: int) -> T[]`
- `upload[T] = (b: GpuBuffer[T], xs: T[], at: int = 0)`: xs written into the buffer from element `at` on (before the dispatches and draws that follow)
- `([])[T] = (b: GpuBuffer[T], i: int) -> T`: one element (in GPU memory, outside compute functions: a slow round trip; cpu() reads many). In compute functions, as on the GPU, reading past either end reads the nearest element and writing there does nothing; elsewhere it is an error.
- `([]=)[T] = (b: GpuBuffer[T], i: int, v: T)`
- `words[T] = (b: GpuBuffer[T]) -> GpuBuffer[u32]`: the same memory as 32-bit words, e.g. for atomic_add on a field of DrawArgs: atomic_add(u.arg_words, 1, u32(1)) counts instances (u.arg_words: words(args))

#### Compute programs

- `struct Compute[P]`: what compute(f) makes of a compute function f(id: int, params: P)
- `struct Compute2[P]`: what compute(f) makes of a compute function over a grid, f(id: ivec2, params: P)
- `struct Compute3[P]`: ... and over a 3D grid, f(id: ivec3, params: P)
- `dispatch[P] = (k: Compute[P], n: int, params: P)`: k's function run for each id in [0, n) with these parameters, in any order and many at once; the dispatches and draws after it see what it wrote
- `dispatch[P] = (k: Compute2[P], size: ivec2, params: P)`: k's function run for each cell of a size.x by size.y grid, id from ivec2(0, 0) to size - 1 (in groups of 8 by 8 on the GPU), as dispatch(k, n, params) runs it for each id in [0, n)
- `dispatch[P] = (k: Compute3[P], size: ivec3, params: P)`: k's function run for each cell of a size.x by size.y by size.z grid (in groups of 4 by 4 by 4 on the GPU)
- `atomic_add = (b: GpuBuffer[i32], i: int, v: i32) -> i32`: Atomic operations on element i of a buffer, for compute functions whose invocations change the same element: each returns the element's old value (past the ends: does nothing, returns 0).
- `atomic_add = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_sub = (b: GpuBuffer[i32], i: int, v: i32) -> i32`
- `atomic_sub = (b: GpuBuffer[u32], i: int, v: u32) -> u32`

- `atomic_and = (b: GpuBuffer[u32], i: int, v: u32) -> u32`

- `atomic_or = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_xor = (b: GpuBuffer[i32], i: int, v: i32) -> i32`
- `atomic_xor = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_exchange = (b: GpuBuffer[i32], i: int, v: i32) -> i32`
- `atomic_exchange = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_min = (b: GpuBuffer[i32], i: int, v: i32) -> i32`
- `atomic_min = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_max = (b: GpuBuffer[i32], i: int, v: i32) -> i32`
- `atomic_max = (b: GpuBuffer[u32], i: int, v: u32) -> u32`
- `atomic_compare_exchange = (b: GpuBuffer[i32], i: int, expected: i32, desired: i32) -> i32`: (the element becomes `desired` if it was `expected`)
- `atomic_compare_exchange = (b: GpuBuffer[u32], i: int, expected: u32, desired: u32) -> u32`

#### Subgroups

- `subgroup_size = () -> int`: In a compute function, the invocations the GPU runs together (a subgroup: 32 of them on NVIDIA, 64 on AMD, fewer on some; 1 on the CPU) combine values without going through memory: subgroup_add(x) is the sum of x over those of them that reach the call together. A program written for any size runs the same everywhere, e.g. one atomic for a subgroup's elements instead of one each: n = subgroup_add(i32(keep))                       # how many of them keep theirs base = 0 if subgroup_elect(): base = int(atomic_add(u.count, 0, n)) slot = subgroup_broadcast_first(base) + int(subgroup_exclusive_add(i32(keep))) These take numbers and vectors (and, or and xor integers and bools too).
- `subgroup_invocation_id = () -> int`
- `subgroup_elect = () -> bool`
- `subgroup_all = (b: bool) -> bool`
- `subgroup_any = (b: bool) -> bool`
- `subgroup_broadcast_first[T] = (x: T) -> T`
- `subgroup_add[T] = (x: T) -> T`
- `subgroup_inclusive_add[T] = (x: T) -> T`
- `subgroup_exclusive_add[T] = (x: T) -> T`

#### Drawing with buffers

- `gpu_mesh[V] = (vertices: GpuBuffer[V], mode: int = GL_TRIANGLES) -> Mesh`: a mesh whose vertices are a buffer's (a compute function may change them between draws)
- `draw_instanced[U, I] = (sh: Shader, m: Mesh, instances: GpuBuffer[I], params: U, first: int = 0, count: int = -1)`: instances drawn with their data in a buffer: count of them from first (count -1: to the end)
- `draw_instanced[U] = (sh: Shader, m: Mesh, count: int, params: U)`: count instances with no data of their own (their shaders tell them apart with instance_id(), e.g. reading a buffer among their uniforms: u.parts[instance_id()])
- `struct DrawArgs`: what one draw of draw_indirect draws (as Vulkan's VkDrawIndexedIndirectCommand)
- `draw_indirect[U] = (sh: Shader, m: Mesh, args: GpuBuffer[DrawArgs], params: U, at: int = 0, draws: int = 1)`: draws whose counts are in a buffer, where a compute function can decide them (GPU-driven drawing): `draws` draws of mesh m, each as args[at + k] says
- `draw_indirect[U, I] = (sh: Shader, m: Mesh, instances: GpuBuffer[I], args: GpuBuffer[DrawArgs], params: U, at: int = 0, draws: int = 1)`: the same with instance data in a buffer
- `draw_indirect_count[U] = (sh: Shader, m: Mesh, args: GpuBuffer[DrawArgs], count: GpuBuffer[u32], params: U, at: int = 0, max_draws: int = -1, count_at: int = 0)`: draws whose number is in a buffer too: as many as count[count_at] says (at most max_draws, -1: all of args from at on), so a compute function can decide it, e.g. counting the draws it writes with atomic_add(u.count, 0, u32(1))
- `draw_indirect_count[U, I] = (sh: Shader, m: Mesh, instances: GpuBuffer[I], args: GpuBuffer[DrawArgs], count: GpuBuffer[u32], params: U, at: int = 0, max_draws: int = -1, count_at: int = 0)`: the same with instance data in a buffer

## Paths

```gdscript
# example: paths
window("Paths", 960, 540)

grid = path_grid(24, 13, 40.0)           # 24 by 13 cells, 40 units across
loop y in [2..11): set_open(grid, 8, y, false)     # two walls
loop y in [0..9): set_open(grid, 16, y, false)
chaser = vec2(60, 260)

update = (dt: f64):
    goal = mouse_pos()
    way = path_step(grid, chaser, goal)  # the next point on the way round the walls
    if distance(way, chaser) > 1.0: chaser += normalize(way - chaser) * f32(200 * dt)

draw = ():
    clear(rgb(0.1, 0.1, 0.13))
    loop y in [0..13):
        loop x in [0..24):
            if not is_open(grid, x, y): rect(f64(x) * 40, f64(y) * 40, 40, 40, GRAY)
    circle(mouse_pos(), 10, YELLOW)
    circle(chaser, 14, RED)
    text("the red one follows the mouse", vec2(20, 500), 20)
```

Paths over a grid, for enemies finding their way round walls: the grid's cells are open or blocked, and path_step() gives, from anywhere, the next point to walk to on the way to a goal. The steps to each goal are worked out once (a flood over the open cells, eight ways round: diagonally only where both sides are open) and kept until the grid changes.

```gdscript
grid = path_grid(40, 30, 16.0)                  # 40 by 30 cells, 16 units across
set_open(grid, 3, 4, false)                     # a wall there
way = path_step(grid, enemy, player)            # walk toward this
```

Positions are vec2: x and y in a 2D game; on the ground of a 3D one, x and z. origin is where the grid's first cell starts (its corner with the least x and y).

- `struct PathGrid`
- `path_grid = (width: int, height: int, cell: f64 = 1.0, origin: vec2 = vec2(0, 0)) -> PathGrid`: a grid with every cell open
- `set_open = (g: mut PathGrid, x: int, y: int, open: bool)`
- `is_open = (g: PathGrid, x: int, y: int) -> bool`: whether a cell is open (outside the grid: no)
- `path_cell = (g: PathGrid, p: vec2) -> ivec2`: the cell a point is in (kept within the grid), and the middle of a cell
- `cell_center = (g: PathGrid, c: ivec2) -> vec2`
- `nearest_open = (g: PathGrid, c: ivec2, reach: int = 4) -> ivec2`: the open cell nearest c, looking up to `reach` cells away (c itself when nothing is open)
- `path_distance = (g: mut PathGrid, from: vec2, to: vec2) -> int`: how many steps from one point to another over open cells (-1: there is no way)
- `path_step = (g: mut PathGrid, from: vec2, to: vec2) -> vec2`: Where to head from `from` on the way to `to`: the middle of the next cell, or `to` itself when it is in the same or the next cell (or cannot be reached). Off the open cells (pushed into a corner, or a goal on a crate), the nearest open cell stands in.

## Particles, noise, easing and collisions

```gdscript
# example: helpers: particles, noise, easing, collisions, a camera that follows and shakes
window("Helpers", 960, 540)

sparks = Particles(gravity = vec2(0, 300))
player = Rect(100, 400, 40, 40)
wall = Rect(500, 380, 60, 120)
t = 0.0
cam = vec2(480, 270)
shake = Shake()

update = (dt: f64):
    t += dt
    if mouse_pressed(.left):
        sparks.emit(screen_to_world(mouse_pos()), 40, 250, ORANGE)
        shake.add(0.5)
    player.x = f32(100 + 700 * ease_in_out((sin(t) + 1.0) / 2.0))
    if every(1, 0.5) and overlaps(player, wall): sparks.emit(center(player), 10, 120, RED)
    sparks.update(dt)
    shake.update(dt)
    # (the camera keeps the player in view: it moves once the player is 200 units off center)
    cam = follow(cam, center(player), dt, 4.0, vec2(200, 1000))

draw = ():
    clear(rgb(0.08, 0.08, 0.1))
    camera2d(cam + shake.offset())
    loop x in [0..48):                    # a row of smooth noise
        h = fbm(f64(x) * 0.15, t * 0.3)
        rect(f64(x) * 20, 300 - 100 * h, 18, 100 * h + 4, rgb(0.3, 0.5, 0.4))
    rect(f64(wall.x), f64(wall.y), f64(wall.w), f64(wall.h), GRAY)
    rect(f64(player.x), f64(player.y), f64(player.w), f64(player.h), if overlaps(player, wall): RED else: CYAN)
    sparks.draw()
    camera2d(vec2(480, 270))
    text("click for sparks (and a shake)", vec2(20, 20), 20)
```

#### Tweens

## Networking

A module (`import net`): messages between programs over WebSockets, so a native build and a web page can play together. A server is a native program; a web page connects to one. See examples/netpong.

```gdscript
# example: networking
import net

window("Chat", 960, 540)

# HOST=1: a server here; else a client of localhost (or ?join=address in a web page)
hosting = env("HOST") != none
if hosting: net.listen(4000)
else: net.connect(env("JOIN") ?? "localhost", 4000)
said: str[]

update = (dt: f64):
    loop e in net.receive():
        if e.kind == .joined: said.push("({e.peer} is here)")
        else if e.kind == .left: said.push("({e.peer} left)")
        else:
            said.push("{e.peer}: {e.text}")
            if hosting: net.send_all(e.data)       # (a server passes each message on)
    if key_pressed(.space): net.send_all("hello at {elapsed():.1} s")

draw = ():
    clear(rgb(0.08, 0.09, 0.12))
    text("Space: say hello", vec2(20, 20), 22)
    loop i in 0.. and line in said[max(said.len() - 18, 0)..]: text(line, vec2(20, 70 + 24 * f64(i)), 20)
```

Networking: messages between programs, over WebSockets, so that the same game reaches others from a native build and from a web page. `import net`, then:

```gdscript
net.listen(4000)                        # a server: others connect to this machine's port 4000
p = net.connect("192.168.1.20", 4000)   # a client: a peer (it connects in the background)
loop e in net.receive():                # what happened since the last call (every frame)
    if e.kind == .joined: ...           # a peer connected (to a server, or the server, to a client)
    if e.kind == .message: print(e.text)
    if e.kind == .left: ...             # it went away (or could not be reached)
net.send(p, "hello")                    # a str or u8[]; net.send_all(...) to every peer
```

Messages arrive whole and in order (WebSockets over TCP). A web page can only connect, not listen: the server is a native program (a game that hosts, or a small server of its own). A page served over https can only reach a wss:// server (TLS: put a proxy that has a certificate, such as Caddy, in front of the server); net.connect("wss://game.example.com") takes a URL as well.

- `enum NetKind: joined, message, left`
- `struct NetEvent`

#### The peers

- `listen = (port: int) -> bool`: start a server on port (native programs); false if the port cannot be had
- `connect = (host: str, port: int = 0) -> int`: connect to a server: a peer, connecting in the background (joined or left arrive by receive); host is a name or address and port its port, or host is a ws:// or wss:// URL (port then unused)
- `send = (peer: int, msg: u8[])`: send a message to a peer (nothing if it is not connected, or has gone)
- `send = (peer: int, msg: str)`
- `send_all = (msg: u8[])`: send a message to every connected peer
- `send_all = (msg: str)`
- `peers = () -> int[]`: the peers connected now
- `close = (peer: int)`: end a connection (a left event follows)
- `receive = () -> NetEvent[]`: what happened since the last call: peers joining and leaving, and their messages, in order

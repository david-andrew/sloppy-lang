# The library

Generated by `tools/apidoc.py` from the library's sources (`lib/`). Everything here is there in every program, without imports. Functions can be called as `f(x, y)` or `x.f(y)`. Each topic starts with a whole program to try.

**For a first game:**

- Shapes: `clear(color)`, `circle(center, radius, color)`, `rect(x, y, w, h, color)`, `line(a, b, width, color)`; colors are `rgb(r, g, b)` from 0 to 1
- Text: `text(s, pos, size, color)`, `text_centered(s, center, size)`; `shadow = rgba(0, 0, 0, 0.7)` to read over a busy scene
- Pictures: `hero = load_texture(embed("hero.png"))` once, then `sprite(hero, pos)` in draw

- Random: `random()` (0 to 1), `random(lo, hi)`, `random_int(lo, hi)` (hi left out), `random_item(xs)`
- Sound: `s = sfx_coin()` (also `sfx_jump`, `sfx_hit`, `sfx_chime`...) once, then `play(s)`; `melody("C4 E4 G4", 120.0)` for music
- Menus: `ui_begin("title", pos)`, then `if ui_button("Play"): ...`, then `ui_end()`
- Timers: `every(1, 2.0)` is true once every 2 seconds (the 1 names the timer: another timer is `every(2, 0.5)`); or count down a number yourself: `wait -= dt`
- Collisions: `circles_overlap(a, ra, b, rb)`, `overlaps(rect_a, rect_b)`, `Rect(x, y, w, h)`
- Camera: `camera2d(player_pos)` at the top of draw keeps the player in the middle; `screen_to_world(mouse_pos())` is where the mouse points in the world (in update too); `reset_transform()` before drawing the score
- Effects: `sparks: Particles`, then `sparks.emit(pos, 20, 200.0, YELLOW, life = 0.5, size = 3.0)`, `sparks.update(dt)` and `sparks.draw()`; `shake: Shake`, `shake.add(0.5)`, `shake.update(dt)`, `camera2d(target + shake.offset())`

## Built-in functions

Part of the language itself: printing, stopping with an error, and a few functions the compiler knows.

```gdscript
# example: built-in functions
print("hello", 42, 3.5, [1, 2, 3])      # any values, separated by spaces
xs = fill(0, 5)                          # five zeros
xs[2] = 7
assert(xs.len() == 5, "five of them")   # stops the program if not true
print(xs, sqrt(2.0), size_of(int))
b = bytes("hi")                          # a string's bytes, as u8[]
print(b, str_from_bytes(b))
if xs[2] != 7: panic("xs[2] changed")   # stop, with a message and where it happened
```

- `print(values...)`: prints the values, separated by spaces, and a line break
- `assert(ok: bool, message: str = "")`: stops the program (with the message, and where) if `ok` is false
- `panic(message: str)`: stops the program, with the message and where each function on the way was called
- `fill[T](x: T, n: int) -> T[]`: an array of `n` copies of `x`
- `sqrt(x: f64) -> f64`: the square root
- `sqrt(x: f32) -> f32`
- `embed(path: str) -> u8[]`: a file's contents, read when the program is compiled and kept in it (the path is relative to the source file)
- `bytes(s: str) -> u8[]`: a string's bytes (UTF-8)
- `str_from_bytes(b: u8[]) -> str`: a string of these bytes
- `size_of(T) -> int`: how many bytes a value of type T takes, and its alignment
- `align_of(T) -> int`
- `int(x)`: a number as a whole number of that type (a float is cut toward zero: int(3.7) is 3); text is read with `to_int(s)`, and a one-character string in single quotes is its code (`u8('A')` is 65)
- `i32(x)`
- `u8(x)`
- `f64(x)`: a number as a float of that size (f32 and f64 also mix by themselves)
- `f32(x)`
- `str(x)`: any value as text, as `print` shows it

## Arrays

`T[]` is a growable array. Arrays are values: assigning one or passing it to a function gives a copy (shared until one of them changes). Functions can be called as `f(xs, y)` or `xs.f(y)`.

```gdscript
# example: arrays
scores = [12, 40, 7, 33]
scores.push(25)                          # add at the end
scores.sort()
print(scores)                            # [7, 12, 25, 33, 40]
print(scores.len(), scores.first(), scores.last(), scores.sum())

big = scores.filter((s): s > 20)         # a new array: [25, 33, 40]
print(big.map((s): s * 2))
print(scores.any((s): s > 35), scores.count((s): s % 2 == 1))

loop i in 0.. and s in scores:           # an index and the elements together
    print("{i}: {s}")

top = scores.pop()                       # take the last one off
scores.insert(0, 1)                      # put one in at the front
print(top, scores, scores.contains(12), scores.index_of(25))
```

#### Built in

- `len(xs: T[]) -> int`: how many elements
- `push(xs: mut T[], x: T)`: adds `x` at the end
- `pop(xs: mut T[]) -> T`: removes the last element and gives it back
- `insert(xs: mut T[], i: int, x: T)`: puts `x` in at index `i`, moving the ones after it along
- `remove(xs: mut T[], i: int) -> T`: takes out the element at `i` and gives it back
- `extend(xs: mut T[], ys: T[])`: adds all of `ys` at the end
- `clear(xs: mut T[])`: removes every element
- `truncate(xs: mut T[], n: int)`: keeps the first `n` elements
- `resize(xs: mut T[], n: int)`: makes it `n` long: new elements are zero
- `reserve(xs: mut T[], n: int)`: makes room for `n` elements without growing again; `cap` is the room there is
- `cap(xs: T[]) -> int`

### array.jo

Generic array utilities. Arrays are values with copy-on-write storage.

- `is_empty[T] = (xs: T[]) -> bool`
- `first[T] = (xs: T[]) -> T`

- `reduce[T, A] = (xs: T[], init: A, f: (A, T) -> A) -> A`
- `find_index[T] = (xs: T[], f: (T) -> bool) -> int`: the index of the first element f is true for, or -1

- `all[T] = (xs: T[], f: (T) -> bool) -> bool`

- `min[T] = (xs: T[]) -> T`
- `max[T] = (xs: T[]) -> T`
- `min_by[T, K] = (xs: T[], key: (T) -> K) -> T`: the element with the smallest key, or the largest (the first of equal ones): the cheapest item, the nearest enemy (min_by(enemies, (e): distance(e.pos, me)))
- `max_by[T, K] = (xs: T[], key: (T) -> K) -> T`
- `unique[T] = (xs: T[]) -> T[]`: each different element once, in the order they first come
- `group_by[T, K] = (xs: T[], key: (T) -> K) -> {K: T[]}`: the elements by a key: each key with the elements that have it, in order (keys in the order they first come)

- `reversed[T] = (xs: T[]) -> T[]`
- `range = (a: int, b: int) -> int[]`
- `enumerate[T] = (xs: T[]) -> (int, T)[]`
- `zip[A, B] = (xs: A[], ys: B[]) -> (A, B)[]`
- `flatten[T] = (xss: T[][]) -> T[]`
- `swap[T] = (xs: mut T[], i: int, j: int)`

#### Sorting

- `(<)[A, B] = (a: (A, B), b: (A, B)) -> bool`: tuples compare element by element, the first that differs deciding (sorting (score, name) pairs sorts by score, then name)
- `(<)[A, B, C] = (a: (A, B, C), b: (A, B, C)) -> bool`
- `sort[T] = (xs: mut T[], descending: bool = false)`: sort in place, smallest first (using <), or largest first; equal elements keep their order
- `sort_with[T] = (xs: mut T[], less: (T, T) -> bool)`: sort in place with a custom "less than" function (equal elements keep their order)
- `sort_by[T, K] = (xs: mut T[], key: (T) -> K, descending: bool = false)`: sort in place by a key, smallest first or largest first (equal keys keep their order: sort by name, then by score, for the scores in order of name)
- `sorted[T] = (xs: T[], descending: bool = false) -> T[]`: a sorted copy of xs
- `sorted_by[T, K] = (xs: T[], key: (T) -> K, descending: bool = false) -> T[]`: a copy of xs sorted by a key

## Strings

`str` is text, in UTF-8. `"{x}"` puts a value in a string; `"{x:.2}"` rounds it to two decimals (more ways: [the language](LANGUAGE.md#2-lexical-structure)). Strings are values, like arrays.

```gdscript
# example: strings
name = "  Sloppy  ".trim()
print(name.upper(), name.len(), name.starts_with("Slo"))

words = "the quick brown fox".split(" ")
print(words, words.join("-"))

# {...} puts a value in a string; after a colon, how to show it
pi = 3.14159
print("pi is about {pi:.2}, a million is {1000000:,}, a quarter is {0.25:.0%}")
print("[{name:<10}] [{name:>10}] [{7:03}]")

n = to_int("42") ?? 0                    # none if it is not a number: 0 instead
print(n + 1, "ab" * 3, "a,b,c".replace(",", "; "))
print("héllo".len(), "héllo".char_count())   # bytes (UTF-8), and characters
```

- `is_alpha = (c: u8) -> bool`
- `is_alnum = (c: u8) -> bool`
- `is_space = (c: u8) -> bool`
- `is_upper = (c: u8) -> bool`
- `is_lower = (c: u8) -> bool`
- `chr = (c: int) -> str`: the character with code point c, as text (UTF-8: one to four bytes); chr(233) is "é"
- `byte_str = (b: int) -> str`: a string of the one byte b (0 to 255; text in UTF-8 is made of these)
- `find = (s: str, sub: str, start: int = 0) -> int`
- `rfind = (s: str, sub: str) -> int`
- `find_byte = (s: str, c: u8, start: int = 0) -> int`
- `contains = (s: str, sub: str) -> bool`
- `starts_with = (s: str, prefix: str) -> bool`
- `ends_with = (s: str, suffix: str) -> bool`
- `trim = (s: str) -> str`: remove spaces, tabs and line breaks from both ends
- `trim = (s: str, chars: str) -> str`: remove any of the characters in `chars` from both ends
- `trim_start = (s: str) -> str`
- `trim_end = (s: str) -> str`
- `split = (s: str, sep: str) -> str[]`: the parts of s between the separators (split("a,b", ",") is ["a", "b"]; with "", the characters)
- `split = (s: str, sep: str, max: int) -> str[]`: split at the first `max` separators only: the rest stays in the last part (split("k=v=w", "=", 1) is ["k", "v=w"])

- `count = (s: str, sub: str) -> int`: how many times sub is in s, not overlapping ("banana".count("an") is 2)
- `pad_start = (s: str, width: int, fill: str = " ") -> str`: s made `width` bytes long with `fill` before it (pad_start("7", 3, "0") is "007"), or after it; a longer s stays as it is ("{s:>10}" and "{s:<10}" in a string do the same with spaces)
- `pad_end = (s: str, width: int, fill: str = " ") -> str`
- `capitalize = (s: str) -> str`: the first letter in upper case ("hello world" -> "Hello world")
- `words = (s: str) -> str[]`: split on runs of whitespace
- `lines = (s: str) -> str[]`
- `join = (parts: str[], sep: str = "") -> str`: sep.join(parts), as in Python
- `join = (sep: str, parts: str[]) -> str`
- `replace = (s: str, old: str, new: str) -> str`
- `repeat = (s: str, n: int) -> str`
- `(*) = (s: str, n: int) -> str`
- `(*) = (n: int, s: str) -> str`
- `upper = (s: str) -> str`
- `lower = (s: str) -> str`
- `to_int = (s: str) -> int?`: parse an integer (decimal, or hex after 0x; _ may separate digits); none if it is not one or does not fit in an int
- `to_float = (s: str) -> f64?`: Parse a decimal number. The result is the double nearest to the exact decimal value (ties to even), like C's strtod: an estimate, then exact big-integer comparisons.

- `reverse = (s: str) -> str`: the characters (code points) in reverse order
- `without_last_char = (s: str) -> str`: number of unicode code points s without its last character (all its bytes: backspace in a text field)
- `char_count = (s: str) -> int`
- `chars = (s: str) -> int[]`: unicode code points of s
- `hash = (s: str) -> u64`: a number made from the text: the same for the same text (for maps, and to pick by name)

## Regular expressions

`regex(r"...")` makes a pattern once; `s.find(r)`, `s.find_all(r)`, `s.matches(r)`, `s.replace(r, "$1")` and `s.split(r)` use it. Raw strings (`r"\d+"`) keep the backslashes as they are.

```gdscript
# example: regex
log = "2026-10-14 08:15 error: disk full\n2026-10-14 08:16 info: retrying\n2026-10-14 08:20 error: gave up"
line = regex(r"^(\S+) (\S+) (\w+): (.*)$")           # made once, used many times
loop m in log.find_all(line):
    if m.groups[2] == "error": print("{m.groups[1]} {m.groups[3]}")

print("ada@example.com".matches(regex(r"[\w.]+@[\w.]+\.\w+")))   # all of it matches
print("a1b22c333".find_all(regex(r"\d+")).map((m): m.text))
print("x = 1, y = 2".replace(regex(r"(\w) = (\d)"), "$2=$1"))
print("one, two;three".split(regex(r"[,;]\s*")))
print("Hello World".replace(regex(r"(?i)o"), "0"))
```

Regular expressions: patterns to find in text, test it against, take apart and replace in.

```gdscript
date = regex(r"(\d{4})-(\d\d)-(\d\d)")
if let m = "due 2026-10-14!".find(date): print(m.text, m.groups[0])   # 2026-10-14 2026
"2026-10-14".matches(date)                       # true: all of the text matches
"a1b22c333".find_all(regex(r"\d+")).map((m): m.text)   # ["1", "22", "333"]
"x = 1, y = 2".replace(regex(r"(\w) = (\d)"), "$2=$1")  # "1=x, 2=y"
"a, b;c".split(regex(r"[,;]\s*"))                       # ["a", "b", "c"]
```

Patterns: . (any character but a line break) [abc] [a-z] [^0-9] \d \w \s (and \D \W \S) ^ $ \b \B, x* x+ x? x{2} x{2,} x{2,5} (and lazy x*? x+? x?? x{2,5}?), a|b, (group) (?:group), \ before any of .[]{}()*+?^$|\ for itself, \n \t \r; (?i) at the start ignores case (in ASCII). Matching takes time in proportion to the text's length times the pattern's (it never backtracks without end), and works on characters (code points), not bytes.

- `struct Regex`
  ```gdscript
  struct Regex:
      pattern: str
      prog: __ReIns[]
      classes: __ReClass[]
      groups: int             # how many ( ) groups it has
      icase = false
      first = -1              # (an ASCII character every match starts with, or -1: skipped to with memchr)
      first_pc = -1           # (the instruction that reads every match's first character, or -1)
  ```
- `struct Match`: one match: where it is (byte offsets), its text, and the text of each ( ) group ("" for a group that took no part)
  ```gdscript
  struct Match:
      start: int
      end: int
      text: str
      groups: str[]
  ```

#### Using one

- `regex = (pattern: str) -> Regex`: a pattern made ready to match (a pattern it cannot read panics, saying where)
- `find = (s: str, r: Regex, from: int = 0) -> Match?`: the first match in s (from byte offset `from` on), or none
- `find_all = (s: str, r: Regex) -> Match[]`: every match in s, from left to right, not overlapping
- `matches = (s: str, r: Regex) -> bool`: the whole of s matches r (not only a part of it)
- `contains = (s: str, r: Regex) -> bool`: r matches somewhere in s
- `replace = (s: str, r: Regex, with: str) -> str`: s with each match of r replaced by `with`, where $0 is the match and $1, $2 ... its groups ($$ for a $)
- `replace = (s: str, r: Regex, f: (Match) -> str) -> str`: s with each match of r replaced by what f makes of it
- `split = (s: str, r: Regex) -> str[]`: the parts of s between the matches of r

## Maps

`{K: V}` maps keys to values, in the order they were added.

```gdscript
# example: maps
ages = {"ada": 36, "alan": 41}
ages["grace"] = 85                       # add or change
print(ages["ada"], ages.len(), ages.has("bob"))
print(ages.get("bob") ?? 0)              # none for a missing key: 0 instead

counts: {str: int} = {}
loop w in "a rose is a rose is a rose".split(" "):
    counts[w] += 1                       # a missing key starts at 0
loop word, n in counts:                  # in the order they were added
    print("{word}: {n}")
counts.remove("is")
print(counts.keys(), counts.values())
```

Hash map {K: V}: insertion ordered, open addressing over a dense entry list. The first two fields must stay `keys` and `vals` (the compiler iterates them in for loops, of a map with nothing gone: __map_live, __map_tidy). A removed entry stays in place, marked gone (so the others keep theirs), its slot a tombstone (1 << 32: probes go on past it); when half of them are gone, they are taken out at once.

- `struct Map[K, V]`
  ```gdscript
  struct Map[K, V]:
      keys: K[]
      vals: V[]
      slots: u64[]      # 0 = empty, otherwise the entry's hash's upper 32 bits | entry index + 1
      hashes: u64[]
      gone: bool[]      # (entries removed since the last compaction: true; shorter than keys when
  ```
- `hash = (x: int) -> u64`: full 64-bit avalanche (murmur3 finalizer): every key bit affects the low bits used for slots, so keys like multiples of 4096 or float bit patterns spread out
- `hash = (x: u64) -> u64`
- `hash = (x: bool) -> u64`
- `hash = (x)`
- `([]=)[K, V] = (m: mut Map[K, V], k: K, v: V)`
- `reserve[K, V] = (m: mut Map[K, V], n: int)`: room for n entries without growing (when many are to come)
- `([])[K, V] = (m: Map[K, V], k: K) -> V`
- `get[K, V] = (m: Map[K, V], k: K) -> V?`
- `get[K, V] = (m: Map[K, V], k: K, default: V) -> V`
- `contains[K, V] = (m: Map[K, V], k: K) -> bool`
- `has[K, V] = (m: Map[K, V], k: K) -> bool`
- `len[K, V] = (m: Map[K, V]) -> int`
- `is_empty[K, V] = (m: Map[K, V]) -> bool`
- `keys[K, V] = (m: Map[K, V]) -> K[]`
- `values[K, V] = (m: Map[K, V]) -> V[]`
- `clear[K, V] = (m: mut Map[K, V])`
- `remove[K, V] = (m: mut Map[K, V], k: K) -> bool`: remove a key; returns true if it was present. The others keep their order.
- `(==)[K, V] = (a: Map[K, V], b: Map[K, V]) -> bool`: the same keys with equal values (in any order) (not for sloppy0: it would take the generic (==) for all structs)

## JSON, CSV and base64

`to_json(value)` and `from_json[T](text)` turn any value (a struct, an array, a map...) into JSON and back; `parse_json` reads JSON of any shape as a `Json` to look inside.

## Bytes and bits

Whole numbers in byte arrays in either byte order (file formats, network messages), counting and turning bits, and bytes from C. A float's bits: `f64_bits` and `f64_from_bits` (math).

```gdscript
# example: bytes
# a WAV file's header, written and read back
n = 1000
h: u8[]
loop c in "RIFF": h.push(c)
append_le(h, 36 + n * 2, 4)
loop c in "WAVEfmt ": h.push(c)
append_le(h, 16, 4)
append_le(h, 1, 2)                       # PCM
append_le(h, 1, 2)                       # one channel
append_le(h, 44100, 4)
print(h.len(), get_le(h, 4, 4), get_le(h, 24, 4))
print(popcount(0b1011), leading_zeros(1), trailing_zeros(8), byte_swap(0x1234, 2) == 0x3412)
```

Bytes and bits: whole numbers in byte arrays (file formats, network messages) in little- or big-endian order, bit counting and turning, and bytes from C.

```gdscript
header: u8[]
append_le(header, 0x46464952, 4)              # "RIFF"
append_le(header, 36 + n, 4)
size = get_le(file, 4, 4)                     # 4 bytes at offset 4, little-endian
rate = get_be(packet, 0, 2)
rate_f = f32_from_bits(u32(get_le(file, 8, 4)))   # a float's bytes
```

Sizes are 1, 2, 4 or 8 bytes; get_le and get_be give the bytes as an unsigned number (8 bytes: its bits as an int), get_le_signed and get_be_signed with their sign.

- `get_le = (b: u8[], at: int, size: int) -> int`: the size-byte number at b[at..], least significant byte first
- `get_be = (b: u8[], at: int, size: int) -> int`: the size-byte number at b[at..], most significant byte first (network order)
- `get_le_signed = (b: u8[], at: int, size: int) -> int`
- `get_be_signed = (b: u8[], at: int, size: int) -> int`
- `put_le = (b: mut u8[], at: int, size: int, v: int)`: v as size bytes at b[at..] (b grows to hold them), least or most significant byte first
- `put_be = (b: mut u8[], at: int, size: int, v: int)`
- `append_le = (b: mut u8[], v: int, size: int)`: v as size bytes at the end of b
- `append_be = (b: mut u8[], v: int, size: int)`

#### Bits

- `popcount = (x: int) -> int`: how many bits are 1
- `leading_zeros = (x: int) -> int`: how many 0 bits come before the highest 1 (64 for 0)
- `trailing_zeros = (x: int) -> int`: how many 0 bits come after the lowest 1 (64 for 0)
- `rotate_left = (x: int, n: int) -> int`: the bits turned by n places (those going out at one end come back at the other)
- `rotate_right = (x: int, n: int) -> int`
- `byte_swap = (x: int, size: int = 8) -> int`: the bytes of a size-byte number in the other order (0x1234, 2 -> 0x3412)

#### From C

- `bytes_from = (p: *u8, n: int) -> u8[]`: a copy of the n bytes at p
- `str_from_c = (p: *u8) -> str`: a copy of C's text at p, up to its zero byte ("" for null)

### text.jo

Values as text and back, for saved games and settings. to_text(value) writes a value the way print shows one inside a list (strings in quotes):

```gdscript

```

from_text[T](text) reads such text back as a T, or says where it is not one (a TextError). Fields go by name, in any order: one the text leaves out keeps its default value, and one the struct does not have (any more) is skipped, so what an older version of a program wrote still reads after its structs change.


- `struct TextError`
  ```gdscript

      message: str
      line: int
      column: int
      path = ""       # where in the value: items[2].count (the message starts with it too)
  ```

- `to_text[T] = (x: T) -> str`
- `from_text[T] = (text: str) -> T \| TextError`
- `from_json[T] = (text: str) -> T \| TextError`: a value of type T from JSON: objects for structs (by field name: a field left out keeps its default, one the struct does not have is skipped) and maps, lists for arrays, tuples and vectors, null for none, an enum's variant by its name in quotes
- `save_value[T] = (name: str, x: T) -> bool`: keep value under name (save_data) as text; false if it could not be written
- `load_value[T] = (name: str, default: T) -> T`: the value kept under name, or default if there is none or it does not read as one

## Threads

```gdscript
# example: threads
slow_square = (n: int) -> int:
    total = 0
    loop i in [0..n): total += n
    total

nums = [loop i in [0..16): 1000000 + i]
squares = parallel_map(nums, slow_square)      # spread over every core
print(cpu_count(), "cores", squares[0], squares[15])

halves = parallel_range(8, (i): i / 2.0)  # f(0) .. f(7), in parallel
print(halves)
```

Data parallelism on a pool of worker threads (fork-join).

```gdscript
squares = parallel_map(nums, (x): x * x)
parallel_update(particles, (p): step(p, dt))      # xs[i] = f(xs[i]), in place
rows = parallel_range(height, (y): render_row(y))
```

The function runs on several threads at once: it may read anything, but it must not change globals or the variables it captured (that would be a data race); return results instead. On the web target everything runs on the calling thread.

- `cpu_count = () -> int`: number of hardware threads available to this process
- `parallel_map[T, U] = (xs: T[], f: (T) -> U) -> U[]`: [loop x in xs: f(x)], computed in parallel (f must not change globals or what it captured)
- `parallel_update[T] = (xs: mut T[], f: (T) -> T)`: xs[i] = f(xs[i]) for every element, in parallel
- `parallel_range[U] = (n: int, f: (int) -> U) -> U[]`: [loop i in [0..n): f(i)], computed in parallel

#### Atomics

- `struct Atomic`: A whole number threads change together: parallel code may change it (and no other variable), as a count of work done or a flag that tells the other threads to stop. Copies of an Atomic are the same number.
  ```gdscript
  found = atomic(-1)
  parallel_range(n, (i: int) -> int:
      if found.get() >= 0: return 0          # another thread found it: skip the rest
      if is_answer(i): found.compare_swap(-1, i)
      0
  )
  ```
- `atomic = (v: int = 0) -> Atomic`
- `get = (a: Atomic) -> int`: its value now
- `add = (a: Atomic, v: int) -> int`: add v (negative: subtract) and give the value after
- `set = (a: Atomic, v: int)`: set it to v
- `compare_swap = (a: Atomic, expected: int, v: int) -> bool`: set it to v if it is `expected` (true), or leave it (false): one thread wins
- `set_max = (a: Atomic, v: int)`: make it at least v (the largest of what the threads give)

## Numeric arrays

Elementwise operators (`.+ .* .^`...), `f.(xs)` and n-dimensional arrays are part of the language: see [arrays for numeric work](LANGUAGE.md#8-arrays-for-numeric-work). These are the functions on them.

```gdscript
# example: numeric arrays
xs = linspace(0.0, 1.0, 5)               # [0.0 0.25 0.5 0.75 1.0]
ys = 3.0 .* xs .^ 2.0 .+ 1.0             # element by element, as one loop
print(ys, sqrt.(xs), xs .> 0.5)
print(mean(ys), dot(xs, ys))

m = [1.0 2.0; 3.0 4.0]                   # a 2 x 2 matrix
print(m.shape, m[1, 0], m * [1.0, 1.0], m * transpose(m))
grid = zeros(3, 4)
grid[1, 2] = 5.0
print(grid)
```

Arrays for numeric work, in the spirit of numpy and MATLAB.

T[,] is an n-dimensional array (NDArray[T]): its elements in row-major order, and its shape. How many dimensions it has is part of the value, as in numpy (T[,,] is the same type; the commas are only for the reader). Write a 2-D one as [1 2; 3 4] (rows separated by ';' or line breaks), stack arrays with [a; b], or make one with zeros(2, 3, 4), ones, eye, rand, reshape. m[i, j] (with as many indexes as dimensions) reads and writes an element; m.shape is its shape. Ranges select parts: m[i, ..] is row i, m[.., j] column j, m[1..2, 0..] a block (ranges include both ends; missing indexes at the end mean whole axes). A part is an array of its own; assigning to one (m[.., 0] = xs, m[0, ..] = 0.0) writes into m.

The dotted operators work element by element on arrays of any shape, and broadcast like numpy (a dimension of length 1, or a missing leading one, stretches to fit): a .* b, m .+ 1.0, v .^ 2, xs .< 0.5, and f.(xs) applies f to each element. A whole dotted expression runs as one loop. On 2-D arrays the plain operators follow linear algebra: a * b is the matrix product.

## The window, the game loop and input

A program that defines `update(dt: f64)` or `draw()` opens a window and calls them every frame. More on windows, screen sizes and the game loop: [the language](LANGUAGE.md#12-programs-and-the-game-loop).

```gdscript
# example: the window, the game loop and input
window("Input", 960, 540)               # the title, and the size of the 2D area

pos = vec2(480, 270)
trail: vec2[] = []

update = (dt: f64):                      # every frame; dt: the seconds since the last one
    pos += input_axis() * 320 * dt  # arrows, W A S D, or a gamepad's stick
    if mouse_down(.left): pos = mouse_pos()
    if key_pressed(.space): trail.clear()
    if key_pressed(.f): toggle_fullscreen()
    if key_pressed(.tab): show_stats(not stats_shown())     # frame times, and the zones' below
    zone("trail")                         # a part of the frame, timed in the statistics
    trail.push(pos)
    if trail.len() > 60: trail.remove(0)
    zone_end()

draw = ():                               # every frame, after update
    clear(rgb(0.08, 0.09, 0.12))
    loop i in 0.. and p in trail: circle(p, 4, rgba(0.3, 0.7, 0.9, i / 60.0))
    circle(pos, 18, ORANGE)
    text("move: arrows, W A S D or click   space: clear   F: fullscreen   Tab: statistics", vec2(20, 20), 20)
    text("{fps():.0} fps, {elapsed():.1} s", vec2(20, 500), 18, GRAY)
```

## Controls and gamepads

```gdscript
# example: controls and gamepads
window("Controls", 960, 540)

# actions with their default keys and buttons; the player can change them (ui_controls)
action("jump", [.key(.space), .key(.w), .button(.a)])
action("left", [.key(.a), .key(.left), .stick(0, -1), .button(.left)])
action("right", [.key(.d), .key(.right), .stick(0, 1), .button(.right)])

x = 480.0
y = 0.0
vy = 0.0
settings = false

update = (dt: f64):
    if key_pressed(.tab): settings = not settings
    if settings: return
    x += action_axis("left", "right") * 300 * dt        # -1 to 1 (a stick gives in between)
    if action_pressed("jump") and y == 0.0: vy = 500.0
    vy -= 1200 * dt
    y = max(0.0, y + vy * dt)

draw = ():
    clear(rgb(0.1, 0.1, 0.14))
    rect(0, 440, 960, 100, rgb(0.25, 0.3, 0.25))
    rect(x - 20, 400 - y, 40, 40, ORANGE)
    text("move: A D or arrows   jump: space or W   Tab: change the controls   ({gamepads().len()} gamepads)", vec2(20, 20), 20)
    if settings:
        ui_begin("controls", vec2(480, 100))
        ui_controls()                    # choose an action, then press its new key or button
        if ui_button("Back") or ui_back(): settings = false
        ui_end()
```

### controls.jo

Controls the player can change. The game names its actions and gives each its default inputs, then asks for actions, never for keys; ui_controls() is a settings screen where the player rebinds them (choose one, press the new key or button), and the bindings are saved.

```gdscript
action("jump", [.key(.space), .button(.a)])
action("left", [.key(.a), .key(.left), .stick(0, -1), .button(.left)])
action("right", [.key(.d), .key(.right), .stick(0, 1), .button(.right)])
...
if action_pressed("jump"): jump()

# in the settings menu:
ui_begin("settings", vec2(640, 140))

if ui_button("Back") or ui_back(): ...

```

- `action_released = (name: str, player: int = -1) -> bool`

### gamepad.jo

Gamepads and joysticks: up to eight at once, each by its number, with a standard layout (Xbox-style names), and every device's own buttons and axes as they are (flight sticks, wheels).

```gdscript
if gamepad_pressed(.a): jump()            # any gamepad
```

  ```gdscript

      vec4(c.rgb * u.params.strength, c.a)
  glow = make_shader(shader(effect_vs, glow_fs))      # once

  no_effect()
  ```

### screen.jo

How a game's picture fits windows of any size and shape.

A game is drawn in 2D units: the size given to window() (its design size), so the same coordinates work in any window. Two settings decide how that maps to the window's pixels:

```gdscript
screen_fit(mode): what a window of another shape shows
    .expand     the design area, scaled to fit, and more around it (the default: no bars,
                nothing cut; visible_rect() says what is shown)
    .letterbox  just the design area, scaled to fit, with bars (letterbox_color) around it
    .crop       the design area scaled to fill the window: what does not fit is cut off
    .stretch    the design area stretched to the window (shapes distort)
    .native     no scaling: one 2D unit is one pixel of the window (screen_size() is its size)

render_resolution(w, h): draw at a fixed resolution, scaled up to the window, by default
    with sharp pixels (nearest) and in whole steps (2x, 3x...); 2D units stay the design size
    (give both the same shape). The picture letterboxes (or crops/stretches with those
    fits). render_resolution(0, 0) goes back to the window's resolution.
pixel_art(): render_resolution at the design size: for a game designed at 320 x 180, one
    2D unit is one sharp pixel. (A window for a design that small opens a whole number of
    times larger.)
render_scale(s): draw at a fraction of the window's pixels (0.5: a quarter of them), scaled
    up smoothly: faster where pixels cost (3D, the software renderer).
```

Drawing that needs it goes to an offscreen canvas, put on the window when the frame ends; the mouse is mapped back the same way (mouse_pos() is in 2D units).

- `enum Fit: expand, letterbox, crop, stretch, native`
- `screen_fit = (mode: Fit)`
- `letterbox_color = (c: vec4)`
- `render_resolution = (w: int, h: int, smooth: bool = false, whole: bool = true)`
- `pixel_art = (smooth: bool = false)`
- `render_scale = (s: f64)`

### tilemap.jo

Tilemaps: layers of tiles drawn from a tileset image. Make one from text (tile_layer: each character is a tile), or load a map made in Tiled (`load_tiled("level.tmx", embed_dir("assets"))`: .tmx or .tmj, with its tilesets and their images found by their paths). Draw it with draw_tilemap, and move boxes through it with tilemap_move, which stops them at solid tiles. Every tile is solid unless set_tile_shape says otherwise: a one-way platform (landed on from above, passed through from below and the sides), a slope (a floor that rises or falls across the tile), or empty (scenery).

```gdscript
tiles = tileset(load_texture(embed("tiles.png"), false), 16, 16)
level = tilemap(tiles, [tile_layer("walls", WALLS, "#=")])     # '#': tile 1, '=': tile 2
update = (dt: f64):
    m = tilemap_move(level, 0, box, vel * f32(dt))
    box = m.rect
    if m.hit_y: vel.y = 0.0
draw = (): draw_tilemap(level)
```

- `struct Tileset`
  ```gdscript
  struct Tileset:
      texture: Texture

      tile_h: int
      columns: int

      spacing = 0                 # pixels between tiles in the image
      margin = 0                  # around them
  ```
- `struct TileLayer`
  ```gdscript
  struct TileLayer:
      name: str

      height: int
      tiles: int[]                # tile ids, a row at a time from the top; 0: no tile

  ```
- `struct MapObject`: an object placed in Tiled (an object layer's): a spawn point, a door, a coin...
  ```gdscript
  struct MapObject:
      name: str
      kind: str                   # its class (Tiled's "type")
      layer: str                  # the object layer it is on
      rect: Rect                  # where (a point: width and height 0)
      props: {str: str}           # its custom properties, as text
  ```
- `enum TileShape:`: how a tile stops what moves through the map (tilemap_move): solid; empty (scenery); platform (one-way: landed on from above, passed through from below and the sides); slope(left, right), a floor whose height (0: the tile's bottom, 1: its top) goes from left at the tile's left side to right at its right side: slope(0, 1) rises to the right, slope(0, 0.5) then slope(0.5, 1) gently over two tiles (passed through from below)
  ```gdscript
  enum TileShape:
      solid
      empty
      platform
      slope(left: f64, right: f64)
  ```
- `struct Tilemap`
  ```gdscript
  struct Tilemap:
      tile_w: int
      tile_h: int
      width: int                  # in tiles
      height: int
      tilesets: Tileset[]
  ```

- `struct TileMove`
  ```gdscript
  struct TileMove:
      rect: Rect                  # where the box ended up
      hit_x: bool                 # it was stopped going sideways
      hit_y: bool                 # ... or up or down (moving down: it landed)
  ```
- `tileset = (t: Texture, tile_w: int, tile_h: int, spacing: int = 0, margin: int = 0) -> Tileset`: a tileset: an image of equal tiles in a grid, numbered from `first` (1) left to right, then down
- `tile_layer = (name: str, rows: str, chars: str) -> TileLayer`: a layer from rows of text: the character at position i of `chars` is tile i + 1, and any other character (a space, a dot) is no tile; a character the rows never use skips a number ("_#": '#' is tile 2). Rows of spaces are rows of the map (open sky); only an empty first line (the line break after the opening quote) and a last line of spaces (before the closing quote) are left out. For tilemap_move every tile is solid, floor tiles too: a tile walked over is `set_tile_shape(map, id, .empty)`, or a character left out of `chars` (no tile).

- `layer_index = (m: Tilemap, name: str) -> int`: the index of the layer with this name (-1: none)
- `tile_at = (m: Tilemap, layer: int, x: int, y: int) -> int`: the tile at column x, row y of a layer (0 outside the map)
- `tile_at = (m: Tilemap, layer: int, p: vec2) -> int`: the tile under a point (in pixels)
- `set_tile = (m: mut Tilemap, layer: int, x: int, y: int, id: int)`
- `set_tile_shape = (m: mut Tilemap, id: int, shape: TileShape)`: how tile id stops what moves (every tile is solid until this says otherwise)
- `tile_shape = (m: Tilemap, id: int) -> TileShape`
- `tilemap_size = (m: Tilemap) -> vec2`: the map's size in pixels

- `tilemap_hits = (m: Tilemap, layer: int, r: Rect) -> bool`: does a box (in pixels) touch a tile of the layer?
- `tilemap_move = (m: Tilemap, layer: int, r: Rect, d: vec2, drop: bool = false) -> TileMove`: move a box by d, stopping it against the layer's tiles: sideways first, then up or down, so it slides along walls and floors. However far it moves in one step, it does not pass through a solid tile. Platforms stop it only coming down onto them (drop: not even then, to drop through one); on a slope it walks up and down the slope's floor, staying on it going down.

### draw3d.jo

3D rendering: camera, sun + sky lighting, fog, shadows, instancing and post effects. Draw calls made during draw() are recorded and rendered (shadow pass, then the lit pass) before any 2D drawing that follows them, so a HUD can be drawn on top.

Directions: y is up, in meters. A turn by `a` about y (`transform(pos, a)`, `rotation_y(a)`) turns +z toward +x, so something turned by `a` faces vec3(sin(a), 0, cos(a)); glTF models face +z unturned, so a model faces a direction d turned by atan2(d.x, d.z). facing(d) turns -z, a camera's front, to d. The cameras (fly, follow, orbit) share one yaw: 0 looks along -z, more turns left, and the way ahead is vec3(-sin(yaw), 0, -cos(yaw)).

### camera3d.jo

Cameras that the player moves (3D): an orbit camera, around a point (to look at a model, a board, a level from above), and a fly camera (to move through a scene). Each is a value the game keeps: update it with the frame's input, then make it the camera.

```gdscript
cam = orbit_camera(vec3(0, 1, 0), 12.0)
update = (dt: f64): update(cam, dt)
draw = ():
    camera3d(cam)
    draw_mesh(...)
```

- `struct OrbitCamera`: Around target, at distance: dragging with the left or right mouse button (or the right stick) turns it, the wheel (or the left stick up and down) brings it closer or further.
  ```gdscript
  struct OrbitCamera:
      target: vec3
      distance: f64 = 10.0
      yaw: f64 = 0.0                 # around the vertical axis, in radians (0: from +z)

      smooth: f64 = 14.0             # how quickly it follows (0: at once)
      drag_left = true               # a left-button drag turns it (false: only the right, the left left to the game)

      shown_pitch: f64 = 0.4
      shown_distance: f64 = 10.0
  ```

- `camera3d = (c: OrbitCamera, fov_degrees: f64 = 60.0, near: f64 = 0.1, far: f64 = 500.0)`
- `struct FollowCamera`: Behind a target the game moves (a third-person camera): the mouse while it is locked (mouse_lock()) or the right button is held, or the right stick, turns it around the target, and the wheel brings it closer. Walk the player along flat_forward and flat_right, so that ahead is where the camera looks: Its yaw is the other cameras': 0 looks along -z, more turns it left.
  ```gdscript
  cam = follow_camera(distance = 6.0)
  update = (dt: f64):
      a = input_axis()
      move = flat_forward(cam) * -a.y + flat_right(cam) * a.x     # (then move the player)
      update(cam, player_pos, dt)
      # kept out of walls: if let h = w.sphere_cast(aim(cam), position(cam), 0.2): pull_in(cam, h.fraction)
  draw = (): camera3d(cam)
  ```
  ```gdscript
  struct FollowCamera:
      target: vec3                   # what it follows (update sets it)
      distance: f64 = 6.0
      height: f64 = 1.5              # how far above the target it aims
      yaw: f64 = 0.0                 # 0: behind the target, looking along -z; more: turned left
      pitch: f64 = 0.35              # looking down from above, in radians
      min_pitch: f64 = -0.3
      max_pitch: f64 = 1.3
      min_distance: f64 = 2.0
      max_distance: f64 = 20.0
      turn_speed: f64 = 0.004        # radians per pixel the mouse moves
      smooth: f64 = 12.0             # how quickly it follows the target (0: at once)
      reach: f64 = 1.0               # (the share of its distance it may be out this frame: pull_in)
      shown_target: vec3
      shown_reach: f64 = 1.0
      placed = false
  ```
- `follow_camera = (distance: f64 = 6.0, yaw: f64 = 0.0, pitch: f64 = 0.35, height: f64 = 1.5) -> FollowCamera`
- `update = (c: mut FollowCamera, target: vec3, dt: f64)`
- `pull_in = (c: mut FollowCamera, fraction: f64)`: a wall between aim(c) and position(c): only this share of the way out (a cast's fraction)
- `aim = (c: FollowCamera) -> vec3`: the point it looks at (above the target), and where it is
- `position = (c: FollowCamera) -> vec3`
- `flat_forward = (c: FollowCamera) -> vec3`: the way it looks along the ground, and its right (for walking where it looks)
- `flat_right = (c: FollowCamera) -> vec3`
- `camera3d = (c: FollowCamera, fov_degrees: f64 = 60.0, near: f64 = 0.1, far: f64 = 500.0)`
- `struct FlyCamera`: Through the scene: W A S D (or the arrows, or the left stick) move, Space and Q go up and down, Shift is faster; the mouse looks around while the right button is held, or always when the mouse is locked (mouse_lock()), as does the right stick.
  ```gdscript
  struct FlyCamera:
      pos: vec3
      yaw: f64 = 0.0                 # 0: looking toward -z
      pitch: f64 = 0.0
      speed: f64 = 8.0               # units per second (Shift: four times that)
      turn_speed: f64 = 0.004
  ```
- `fly_camera = (pos: vec3, yaw: f64 = 0.0, pitch: f64 = 0.0) -> FlyCamera`
- `forward = (c: FlyCamera) -> vec3`: the way it looks (a unit vector), and its right
- `right = (c: FlyCamera) -> vec3`
- `update = (c: mut FlyCamera, dt: f64)`
- `camera3d = (c: FlyCamera, fov_degrees: f64 = 60.0, near: f64 = 0.1, far: f64 = 500.0)`

## Models (glTF)

3D models from glTF 2.0 files (.glb, or .gltf with its .bin and images), the format Blender and most tools export: meshes, with their materials' base color (a factor and a texture, PNG or JPEG), vertex colors and emissive light, placed by the scene's nodes; skins (meshes bent by a skeleton of nodes, up to 64 joints) and their animations.

```gdscript
ship = load_model(embed("ship.glb"))
draw = ():
    camera3d(...)
    draw_model(ship, translation(pos) * rotation_y(angle))
```

An animated model is drawn in a pose: an animation at a time, or two blended.

```gdscript
run = find_animation(hero, "Run")
draw_model(hero, transform(pos, facing), pose = pose_at(hero, run, elapsed()))
```

A .gltf names its other files: give them by those names, as `files` (or put them in the .gltf as data: URIs). Not read: morph targets, compressed meshes (Draco, meshopt), sparse accessors; materials beyond the base color (metal, roughness, normal maps).

- `struct ModelPart`
  ```gdscript
  struct ModelPart:
      mesh: Mesh
      transform: mat4             # where the scene's nodes put it, in the model
      color: vec4                 # the material's base color (times the vertices' colors)
      texture: Texture            # its base color texture (Texture(0, 0, 0): none)
      emissive: f64               # how much it glows (from the material's emissive color)
      node: int = -1              # the node it hangs from (in Model.nodes)
      skin: int = -1              # the skin that bends it (in Model.skins; -1: none)
  ```
- `struct ModelNode`: a node of the model's scene: its name, its parent (-1: none), and where it rests, from its parent: a translation, a rotation (a quaternion) and a scale
  ```gdscript
  struct ModelNode:
      name: str
      parent: int
      t: vec3
      r: vec4
      s: vec3
  ```
- `struct Skin`: the joints (nodes) that bend a skin's vertices, and the inverse of where each was when the mesh was bound to them
  ```gdscript
  struct Skin:
      joints: int[]
      inverse_bind: mat4[]
  ```
- `struct AnimChannel`: keys moving one node: its translation (path 0), rotation (1) or scale (2) at the times given (3 values a key, 4 for rotations), in steps or blended between keys
  ```gdscript
  struct AnimChannel:
      node: int
      path: int
      step: bool
      times: f32[]
      values: f32[]
  ```
- `struct ModelAnimation`
  ```gdscript
  struct ModelAnimation:
      name: str
      length: f64                 # (seconds)
      channels: AnimChannel[]
  ```
- `struct Pose`: every node's translation, rotation and scale (by node, as in Model.nodes)
  ```gdscript
  struct Pose:
      t: vec3[]
      r: vec4[]
      s: vec3[]
  ```
- `struct Model`
  ```gdscript
  struct Model:
      parts: ModelPart[]
      min: vec3                   # the corners of a box around it (in its resting pose)
      max: vec3
      nodes: ModelNode[] = []
      order: int[] = []           # (the nodes, each after its parent)
      skins: Skin[] = []
      animations: ModelAnimation[] = []
  ```
- `struct ModelError`
  ```gdscript
  struct ModelError:
      message: str
  ```
- `struct MeshData`: A model's data before it goes to the GPU (read_gltf): the vertices (in each part's own space) for collision, or to change them, and the images of its textures.
  ```gdscript
  struct MeshData:
      vertices: Vertex3D[]
      indices: u32[]              # (none: the vertices are the triangles)
      transform: mat4
      color: vec4
      image: int                  # its texture's image in ModelData.images (-1: none)
      emissive: f64
      node: int = -1
      skin: int = -1
      joints: vec4[] = []         # (skinned: per vertex, 4 joints (by their place in the skin)
      weights: vec4[] = []        # and how much each bends it)
  ```
- `struct ModelData`
  ```gdscript
  struct ModelData:
      meshes: MeshData[]
      images: Image[]
      smooth: bool[]              # (per image: filtered, or nearest pixels)
      min: vec3
      max: vec3
      nodes: ModelNode[] = []
      order: int[] = []
      skins: Skin[] = []
      animations: ModelAnimation[] = []
  ```
- `model = (d: ModelData) -> Model`: the model on the GPU: a mesh and a texture for each part
- `draw_model = (m: Model, transform: mat4 = mat4(), tint: vec4 = vec4(1, 1, 1, 1), cast_shadow: bool = true, pose: Pose = Pose([], [], []), in_front: bool = false)`: Draw each part (see draw_mesh), the model placed by transform and its colors times tint. An animated model is drawn in the pose given (pose_at, blend_poses), or as it rests.

#### Poses

- `rest_pose = (m: Model) -> Pose`: every node as it rests
- `find_animation = (m: Model, name: str) -> int`: the animation with this name (or whose name ends "|name", as Blender's "Armature|Run"); -1: none
- `animation_length = (m: Model, anim: int) -> f64`
- `pose_at = (m: Model, anim: int, time: f64, looped: bool = true) -> Pose`: ModelAnimation anim at a time (seconds): looped, or held at its end. Nodes it does not move rest.

#### An animation player

- `struct Animator`: plays a model's animations by name, fading from one to the next:
  ```gdscript
  anim: Animator
  anim.play(robot, "Run")                          # in update: what it does now (again: no restart)
  anim.play(robot, "Jump", looped = false)          # once, then anim.finished
  anim.update(robot, dt)
  if anim.passed(0.3): play_at(step_sound, pos)     # the frame it goes past 0.3 s (footsteps)
  draw_model(robot, transform(pos), pose = anim.pose(robot))
  ```
  ```gdscript
  struct Animator:
      current = -1            # the animation playing (find_animation's number; -1: none)
      time = 0.0              # how far into it, in seconds
      looped = true
      speed = 1.0
      finished = false        # one played once has come to its end (it holds its last pose)
      last_time = 0.0         # (time before the last update)
      prev = -1               # (the one fading out, where it was, and how far the fade has come)
      prev_time = 0.0
      prev_looped = true
      fade = 0.0
      faded = 0.0
  ```
- `play = (a: mut Animator, m: Model, name: str, looped: bool = true, fade: f64 = 0.2, speed: f64 = 1.0, restart: bool = false)`: play the animation named `name` (already playing: it goes on; restart = true starts it over), fading in over `fade` seconds
- `update = (a: mut Animator, m: Model, dt: f64)`
- `passed = (a: Animator, m: Model, t: f64) -> bool`: the last update went past time t of the animation (once per loop, for a looped one)
- `pose = (a: Animator, m: Model) -> Pose`: the pose to draw (the fade from the one before, while it lasts)
- `blend_poses = (a: Pose, b: Pose, k: f64) -> Pose`: between two poses of the same model: k = 0 is a, 1 is b (to fade from one animation to the next)
- `find_node = (m: Model, name: str) -> int`: the node with this name (or whose name ends ":name", as Mixamo's "mixamorig:Head"); -1: none
- `node_transform = (m: Model, p: Pose, node: int) -> mat4`: where a node is in the model, posed (to hold something in a hand: transform * this)
- `turn_node = (m: Model, p: mut Pose, node: int, axis: vec3, angle: f64)`: turn a node of a pose by angle (radians) round an axis in the model's space (a spine bent to aim up or down, a head turned to look)
- `model_size = (m: Model) -> vec3`: the model's size (the box around it) and its middle
- `model_center = (m: Model) -> vec3`
- `load_model = (file: u8[], files: {str: u8[]} = {}) -> Model`: load_gltf, or a panic with what is wrong
- `load_gltf = (file: u8[], files: {str: u8[]} = {}) -> Model \| ModelError`: a .glb (binary glTF) or .gltf (its JSON) file, on the GPU; files: the ones it names, by name
- `read_gltf = (file: u8[], files: {str: u8[]} = {}) -> ModelData \| ModelError`: the same, its data only (see ModelData)

## Sound and music

```gdscript
# example: sound
window("Sound", 960, 540)

beep = tone(440.0, 0.2, .square, 0.3)                      # a note, made by the program
zap = tone(900.0, 0.3, .saw, 0.3, slide = 0.3)             # sliding down to 0.3 of its pitch
chord = mix([tone(262.0, 0.6), tone(330.0, 0.6), tone(392.0, 0.6)])
song = melody_loop("C4 E4 G4 E4 F4 A4 C5 A4", 140.0)
music = play(song, 0.5, looping = true)

update = (dt: f64):
    if key_pressed(.a): play(beep)
    if key_pressed(.s): play(zap, pan = -0.8)                # more to the left
    if key_pressed(.d): play(chord)
    if key_pressed(.f): play(sfx_coin())
    if key_pressed(.m): set_volume(music, 0.0)
    # (from where the mouse is, heard from the middle: to the left or right, fainter further away)
    if mouse_pressed(.left): play_at(beep, mouse_pos(), vec2(480, 270), reach = 600)

draw = ():
    clear(rgb(0.1, 0.1, 0.14))
    text("A: beep   S: zap   D: chord   F: coin   M: quiet   click: a beep from there", vec2(20, 20), 24)
    text("(in a browser, click the page first: pages may not play sound before)", vec2(20, 60), 18, GRAY)
```

### audio.jo

Audio: a software mixer written in Sloppy. Sounds are float sample buffers (stereo, interleaved, at the mixer rate). Each frame the mixer renders just enough samples to keep the output device fed: on Linux through ALSA, on Windows waveOut, on macOS AudioQueue, in a web page Web Audio (silent where there is none, or with SLOPPY_NO_AUDIO=1). Web: WebAudio.

- `struct Sound`: A Sound is its samples: make one from your own, `Sound(samples)`, for synthesis (left and right in turn, at MIX_RATE a second, from -1 to 1). The mix: each voice's samples times its volume, its pan taken from the other side (pan 1: the left channel silent, the right as loud as at 0), times master_volume; what goes past 0.75 is bent smoothly toward 1.
  ```gdscript
  struct Sound:
      samples: f32[]      # interleaved stereo
  ```
- `struct Voice`
  ```gdscript
  struct Voice:
      sound: Sound
      pos: f64
      volume: f32
      pan: f32
      pitch: f64
      looping: bool
      id: int
      stream = false      # music, decoded as it plays (play_music): its __Stream has this id
      fade_to: f32 = 0.0  # (fade_volume: the volume it is going to, in fade_time seconds)
      fade_time = 0.0
      fade_stop = false   # (fade_out: stopped when the fade ends)
      wait = 0            # (play's delay: frames of the mix before it starts)
  ```
- `enum Wave: sine, square, triangle, saw, noise`
- `const MIX_RATE = 48000`
- `frames = (s: Sound) -> int`
- `duration = (s: Sound) -> f64`
- `play = (s: Sound, volume: f64 = 1.0, pan: f64 = 0.0, pitch: f64 = 1.0, looping: bool = false, delay: f64 = 0.0) -> int`: play a sound; returns a voice id for stop()/set_volume(). It starts with the mixer's next samples (made each frame, a little ahead of what is heard), or `delay` seconds after them, to the sample: for music, `play(kick, delay = beat_at - audio_time())` starts each note on time whatever the frame rate
- `audio_time = () -> f64`: the audio clock: seconds of sound the mixer has made (ahead of what is heard by the output's latency, about 20-60 ms); what play's delay counts from. It runs on in step with the sound, not the frames: a beat kept by it does not drift when frames are slow or dt is capped
- `stop = (id: int)`
- `stop_all = ()`
- `is_playing = (id: int) -> bool`
- `set_volume = (id: int, volume: f64)`
- `fade_volume = (id: int, volume: f64, seconds: f64)`: change a voice's volume gradually, over `seconds`
- `fade_out = (id: int, seconds: f64 = 1.0)`: fade a voice to silence over `seconds`, then stop it
- `crossfade = (old: int, s: Sound, seconds: f64 = 1.0, volume: f64 = 1.0, looping: bool = true) -> int`: fade out the voice `old` while `s` starts silent and fades in to `volume`: from one music or ambience loop to the next (returns the new voice; old may be 0 or already stopped)
- `set_pitch = (id: int, pitch: f64)`
- `set_pan = (id: int, pan: f64)`

#### Sounds in a place

- `play_at = (s: Sound, pos: vec2, listener: vec2, volume: f64 = 1.0, reach: f64 = 1200.0, pitch: f64 = 1.0) -> int`: play a sound from a place in 2D: to the left or right of listener (who hears it: the player, or the camera's target), and quieter further away, silent beyond reach (2D units)
- `play_at = (s: Sound, pos: vec3, volume: f64 = 1.0, reach: f64 = 40.0, pitch: f64 = 1.0) -> int`: play a sound from a place in 3D: heard from the camera (camera3d), to its left or right, and quieter further away, silent beyond reach (meters)
- `move_sound = (id: int, pos: vec3, volume: f64 = 1.0, reach: f64 = 40.0)`: a sound already playing (play_at's voice) moved to another place in 3D: a looping engine, a fire that the player walks past (call it every frame)

#### Volume

- `master_volume = (v: f64)`: the volume of everything played, from 0 (silent) to 1
- `master_volume = () -> f64`: the volume set with master_volume (0.8 to start with)

#### Making sounds

- `tone = (freq: f64, seconds: f64, wave: Wave = .sine, volume: f64 = 0.5, attack: f64 = 0.005, release: f64 = 0.1, slide: f64 = 1.0, vibrato: f64 = 0.0) -> Sound`: a single synthesized note: frequency slides from freq to freq * slide over the duration
- `mix = (sounds: Sound[]) -> Sound`: mix several sounds into one (useful for chords and layered effects)
- `sfx_jump = () -> Sound`: sound effect presets
- `sfx_coin = () -> Sound`
- `sfx_hit = () -> Sound`
- `sfx_explosion = () -> Sound`
- `sfx_laser = () -> Sound`
- `sfx_powerup = () -> Sound`
- `sfx_click = () -> Sound`
- `sfx_whoosh = () -> Sound`
- `sfx_chime = () -> Sound`
- `note_freq = (name: str) -> f64`: note name ("C4", "F#3", "Bb5") to frequency in Hz
- `midi_freq = (n: f64) -> f64`: the frequency of a MIDI note number: 69 is A4, 440 Hz; 60 middle C
- `melody = (notes: str, bpm: f64 = 120.0, wave: Wave = .triangle, volume: f64 = 0.3, step: f64 = 0.5) -> Sound`: render a melody: notes separated by spaces, "-" holds the previous note, "." is a rest; each lasts `step` beats (0.5: eighth notes at bpm)
- `melody_loop = (notes: str, bpm: f64 = 120.0, wave: Wave = .triangle, volume: f64 = 0.3, step: f64 = 0.5) -> Sound`: a melody made to be played with looping = true: exactly as long as its notes, with the end of the last ones (and their release) carried round to the start, so the loop has no seam

#### WAV files

- `load_wav = (file: u8[]) -> Sound`: a WAV file's sound: integer samples of 8, 16, 24 or 32 bits or floats of 32 or 64, any number of channels (the first two are used; mono plays on both), any rate (resampled to MIX_RATE). Other files are an error that says what they are.

### vorbis.jo

OGG Vorbis: load_ogg decodes a whole .ogg file into a Sound. Vorbis is the usual format for game music: about a tenth of the size of a WAV. (Written from the Vorbis I specification.)

```gdscript
music = load_ogg(embed("music.ogg"))
play(music, 0.6, looping = true)
```

- `load_ogg = (file: u8[]) -> Sound`: a whole Ogg Vorbis file, at the mixer's rate, in stereo (mono is copied to both sides; files with more channels give their front left and right). A file it cannot read stops the program with a message saying why.

#### Music: decoded while it plays

- `struct Music`: A long piece of music played as it is decoded, a little ahead of where it is playing: no wait when it loads and little memory (a three-minute song decoded whole is about 70 MB).
  ```gdscript
  song = load_music(embed("song.ogg"))
  id = play_music(song, 0.6)          # looping; stop(id), set_volume(id, v) as for sounds
  ```
  ```gdscript
  struct Music:
      file: u8[]
      channels: int
      rate: int
      seconds: f64                # how long it is (0: unknown)
  ```
- `load_music = (file: u8[]) -> Music`
- `play_music = (m: Music, volume: f64 = 1.0, looping: bool = true, pan: f64 = 0.0) -> int`: play music from its start; returns a voice id for stop(), set_volume() and is_playing()
- `crossfade = (old: int, m: Music, seconds: f64 = 1.0, volume: f64 = 1.0, looping: bool = true) -> int`: fade out the voice `old` while music m starts silent and fades in to `volume` (returns the music's voice; old may be 0 or already stopped)
- `struct OggAudio`: the samples as the file has them (interleaved, d.channels of them, at d.rate)
  ```gdscript
  struct OggAudio:
      channels: int
      rate: int
      samples: f32[]
      error = ""                  # why it could not be read ("": it could)
  ```

## GPU programs

```gdscript
# example: GPU programs
window("Shader", 960, 540)

struct Vertex:
    pos: vec2
struct Params:
    time: f32
    size: vec2
struct Out:
    pos: vec4                            # (the first field: where on the screen)
    uv: vec2

vs = (v: Vertex, u: Params) -> Out: Out(vec4(v.pos, 0, 1), v.pos * 0.5 + 0.5)
fs = (i: Out, u: Params) -> vec4:        # runs for every pixel, on the GPU
    p = (i.uv - 0.5) * vec2(u.size.x / u.size.y, 1.0)
    d = length(p)
    rgb(0.5 + 0.5 * sinf(d * 30.0 - u.time * 4.0), 0.3, 0.6 + 0.4 * cosf(u.time + p.x * 3.0))

prog = make_shader(shader(vs, fs))
quad = mesh([Vertex(vec2(-1, -1)), Vertex(vec2(1, -1)), Vertex(vec2(1, 1)),
             Vertex(vec2(-1, -1)), Vertex(vec2(1, 1)), Vertex(vec2(-1, 1))])
t = 0.0
update = (dt: f64): t += dt
draw = (): draw(prog, quad, Params(t, vec2(960, 540)))
```

GPU programs written in Sloppy: meshes, shaders and uniform binding.

```gdscript
struct Vertex: pos: vec3; color: vec4          -> vertex attributes
struct Params: mvp: mat4                        -> uniforms
struct Out:    pos: vec4; color: vec4           -> first field is the clip position
vs = (v: Vertex, u: Params) -> Out: Out(u.mvp * vec4(v.pos, 1), v.color)
fs = (i: Out, u: Params) -> vec4: i.color
prog = make_shader(shader(vs, fs))
m = mesh(vertices)
draw(prog, m, Params(mvp))
```

Uniform fields are numbers, vectors, mat4 and Texture, or fixed-size arrays of them (`bones: mat4[64]`, `lights: vec4[8]`), and GPU buffers (gpubuffer.jo: `u.particles[i]`). Shader code can use fixed-size arrays, `loop` over them, and sample(), sample_lod(), texel(), texture_size(), discard() (fragment) and vertex_id(), instance_id() (vertex).

- `struct ShaderSource`: produced by the compiler from shader(vs, fs)
  ```gdscript
  struct ShaderSource:
      vs: str
      fs: str
      layout: str
      cpu_vs: *u8           # the shader functions, for the software renderer
      cpu_fs: *u8
      out_size: int         # bytes of the vertex function's result
      vs_args: int          # 2: vs(vertex, uniforms), 3: vs(vertex, instance, uniforms)
      flat: str             # per 4 bytes of that result: 'f' interpolated, 'i' passed on unchanged
      vs_spirv: str         # the stages as SPIR-V, for Vulkan (compiler/spirv.jo; "" on the web)
      fs_spirv: str
  ```
- `struct ShaderAttrib`
  ```gdscript
  struct ShaderAttrib:
      comps: int
      offset: int
  ```
- `struct ShaderUniform`
  ```gdscript
  struct ShaderUniform:
      loc: int
      kind: u8
      offset: int
      count: int            # an array (T[N] field): N, and the bytes per element
      stride: int
      loc2: int = -1        # a GPU buffer: its length's location (loc: its texture's)
  ```
- `struct Shader`
  ```gdscript
  struct Shader:
      prog: int
      stride: int
      attribs: ShaderAttrib[]
      uniforms: ShaderUniform[]
      usize: int
      istride: int
      iattribs: ShaderAttrib[]
      ibase_loc: int = -1   # (OpenGL) where instance_id() starts: see draw_indirect
  ```
- `struct Mesh`
  ```gdscript
  struct Mesh:
      vao: int
      vbo: int
      ibo: int
      count: int
      index_count: int
      stride: int
      mode: int
      instance_vbo: int
      instances: int
      center: vec3                # a sphere around the vertices (radius < 0: not known), for
      radius: f32 = -1.0          # leaving out what the camera cannot see (draw3d.jo)
      gbuf: int                   # the vertices are a GPU buffer's (gpu_mesh): its number
      keep: u8[]                  # (and what keeps that buffer alive)
  ```
- `make_shader = (src: ShaderSource) -> Shader`
- `mesh[V] = (vertices: V[], indices: u32[] = [], mode: int = GL_TRIANGLES) -> Mesh`: upload vertices (any struct type matching the shader's vertex input) and optional indices
- `update_mesh[V] = (m: mut Mesh, vertices: V[])`
- `draw[U] = (sh: Shader, m0: Mesh, params: U)`: draw a mesh with a shader; `params` is the uniforms struct the shader functions take
- `draw_instanced[U, I] = (sh: Shader, m: mut Mesh, instances: I[], params: U)`: draw many copies of a mesh in one call; `instances` holds the per-instance shader input (uploaded on every call: for instances that change rarely, keep them on the GPU with instance_buffer)
- `struct InstanceBuffer[I]`: per-instance shader input kept on the GPU: uploaded once (and again by set_instances), drawn any number of times with draw_instanced
  ```gdscript
  struct InstanceBuffer[I]:
      vbo: int
      count: int
  ```
- `instance_buffer[I] = (instances: I[]) -> InstanceBuffer[I]`
- `set_instances[I] = (b: mut InstanceBuffer[I], instances: I[])`: replace what an instance buffer holds
- `draw_instanced[U, I] = (sh: Shader, m: Mesh, b: InstanceBuffer[I], params: U, first: int = 0, count: int = -1)`: draw instances first .. first + count of a buffer (count -1: to the end)
- `sample = (t: Texture, uv: vec2) -> vec4`: texture lookup inside shader functions (maps to GLSL texture()); outside the software renderer, calling it on the CPU returns white
- `sample_lod = (t: Texture, uv: vec2, lod: f32) -> vec4`: texture lookup at a given mipmap level (maps to GLSL textureLod; the software renderer has no mipmaps and samples the full-size image)
- `texel = (t: Texture, p: ivec2) -> vec4`: the texel at integer coordinates p (0 to size - 1; y = 0 is the first row of the image data): no filtering or wrapping (maps to GLSL texelFetch)
- `texture_size = (t: Texture) -> ivec2`: a texture's size in texels (maps to GLSL textureSize)
- `discard = ()`: in a fragment shader: drop this fragment (no color, no depth), e.g. for alpha-tested leaves: `if c.a < 0.5: discard()`. The rest of the function still runs on the CPU; its result is unused.
- `vertex_id = () -> int`: in a vertex shader: the index of the vertex being shaded (GLSL gl_VertexID) and of the instance (gl_InstanceID: 0 for draw, the index into the instances for draw_instanced)
- `instance_id = () -> int`
- `fwidth = (x: f32) -> f32`: in a fragment shader: how much x changes from one pixel to the next (GLSL fwidth), e.g. for edges that stay sharp at any size; 0 on the CPU
- `fract = (v: vec2) -> vec2`
- `step = (edge: f32, x: f32) -> f32`

## GPU arrays

```gdscript
# example: GPU arrays
xs = gpu(linspace(0.0, 1.0, 1000000))    # a million numbers, on the GPU
ys = xs .* xs .+ 1.0                     # one GPU program, run on all of them
print(gpu_available(), sum(ys), mean(ys), max(ys))
print(cpu(ys).data[999999])              # back on the CPU
```

GPU arrays: numbers kept in GPU memory and computed on by GPU programs.

```gdscript
g = gpu(xs)                       # upload (up to 4 dimensions)
h = g .* 2.0 .+ sin.(g)           # one GPU program, made from the expression at compile time
ys = cpu(h)                       # download: an array of the same shape
total = sum(h)                    # reductions too
```

Values are f32, or i32 for arrays made from integers (gpu(int_array)): integer arithmetic keeps integer semantics (7 / 2 is 3), and mixing with floats gives floats. A dotted expression whose arrays are GPU arrays runs on the GPU as one program (the functions applied with f.(g) are translated like shader functions; numbers in the expression become its parameters). Shapes broadcast as on the CPU. Native programs use Vulkan where they can: an array is a buffer, the program a compute program (compiler/spirv.jo, spirv_kernel), with or without a window. Otherwise they use OpenGL ES (without a window, through a windowless EGL context), and web builds WebGL 2: an array is a float texture holding four values per texel, the program a fragment program drawn over it. Where none of these can (no driver, SLOPPY_SOFTWARE=1, an old browser, node) the same expressions run on the CPU, so programs work everywhere; gpu_available() tells which.

- `struct GpuArray[T]`
  ```gdscript
  struct GpuArray[T]:
      n: int
      w: int
      h: int
      tex: int          # the texture holding the values (0: there is no GPU; they are in host)
      host: T[]
      token: u8[]       # shared by all copies of this value; see __gpu_alloc
      shape: int[]
  ```
- `gpu_available = () -> bool`

## GPU buffers and compute

For programs that keep their data on the GPU: buffers of any struct, functions run once per element (`compute`, `dispatch`) and draws the GPU decides (`draw_indirect`). Through Vulkan these run on the GPU; elsewhere on the CPU, so programs work everywhere.

```gdscript
# example: GPU buffers and compute
window("Swarm", 960, 540)

struct Bug:
    pos: vec2
    vel: vec2
struct Step:
    bugs: GpuBuffer[Bug]
    dt: f32
    time: f32

# runs on the GPU, once for each bug
step = (id: int, u: Step):
    b = u.bugs[id]
    a = id * 0.000314 + u.time * 0.3
    r = 0.45 + 0.3 * sinf(a * 5.0 + u.time)
    goal = vec2(cosf(a) * r * 0.5625, sinf(a) * r)
    b.vel = b.vel * 0.94 + (goal - b.pos) * u.dt * 12.0
    b.pos += b.vel * u.dt
    u.bugs[id] = b

struct Corner:
    at: vec2
struct Look:
    bugs: GpuBuffer[Bug]
struct Out:
    pos: vec4
    color: vec4

vs = (c: Corner, u: Look) -> Out:
    b = u.bugs[instance_id()]
    Out(vec4(b.pos + c.at * vec2(0.004, 0.007), 0, 1), vec4(0.3 + length(b.vel) * 3.0, 0.7, 1.0 - length(b.vel) * 2.0, 1))
fs = (i: Out, u: Look) -> vec4: i.color

bugs = gpu_buffer([loop i in [0..20000): Bug(vec2(sinf(i), cosf(i * 1.7)) * 0.9, vec2(0, 0))])
stepper = compute(step)
prog = make_shader(shader(vs, fs))
quad = mesh([Corner(vec2(-1, -1)), Corner(vec2(1, -1)), Corner(vec2(0, 1))])
t = 0.0
update = (dt: f64):
    t += dt
    dispatch(stepper, len(bugs), Step(bugs, dt, t))
draw = ():
    clear(rgb(0.05, 0.06, 0.1))
    draw_instanced(prog, quad, len(bugs), Look(bugs))
```

GPU buffers and compute programs: arrays kept in GPU memory, and functions written in Sloppy that run on the GPU once per element.

```gdscript
struct Particle: pos: vec2; vel: vec2
struct Step: parts: GpuBuffer[Particle]; dt: f32
step = (id: int, u: Step):                    # a compute function: (id, parameters)
    p = u.parts[id]
    p.pos += p.vel * u.dt
    u.parts[id] = p
parts = gpu_buffer(particles)                 # upload (gpu_buffer[Particle](n): n zeros)
stepper = compute(step)                       # the program (the compiler makes it)
dispatch(stepper, len(parts), Step(parts, dt))    # step(id, ...) for each id in [0, len(parts))
ps = cpu(parts)                               # download
```

A compute function over a grid takes id: ivec2 (dispatch(k, ivec2(w, h), params)).

Shaders read buffers among their uniforms (`u.parts[instance_id()]`); a buffer can also be a mesh's vertices (gpu_mesh), a draw's instances (draw_instanced) and the counts of draws the GPU decides (draw_indirect with DrawArgs; draw_indirect_count: how many draws, too). Only compute functions write buffers; atomic_add() and the others change an element of a GpuBuffer[i32] or GpuBuffer[u32] that many invocations change at once. What a dispatch writes is seen by every dispatch and draw after it.

Through Vulkan a buffer is GPU memory read by its address and a compute function a compute program (compiler/spirv.jo); elements are laid out as the CPU lays them out. Elsewhere (OpenGL, the software renderer, the web) buffers are in CPU memory and compute functions run on the CPU, on every core; shaders read buffers through a copy in an integer texture. So programs run everywhere: gpu_compute() tells which way.

- `struct GpuBuffer[T]`
  ```gdscript
  struct GpuBuffer[T]:
      addr: int             # its address in GPU memory (Vulkan): what GPU programs read
      n: int
      id: int               # its entry in __gb
      host: *T              # its elements, when they are in CPU memory (else null)
      token: u8[]           # shared by every copy of this value: see __gb_reclaim
  ```
- `gpu_compute = () -> bool`: whether buffers are in GPU memory and compute functions run on the GPU (Vulkan: the window's, or one with no window), or else in CPU memory and on the CPU

#### Making, reading and writing buffers

- `gpu_buffer[T] = (n: int) -> GpuBuffer[T]`: a buffer of n elements, all zero: gpu_buffer[Particle](1000). Elements are plain data (numbers, bools, vectors and structs of them; no strings, arrays or functions)
- `gpu_buffer[T] = (xs: T[]) -> GpuBuffer[T]`: a buffer holding a copy of xs
- `len[T] = (b: GpuBuffer[T]) -> int`
- `cpu[T] = (b: GpuBuffer[T]) -> T[]`: all the elements, or count of them from first (after what the GPU was given to do has run)
- `cpu[T] = (b: GpuBuffer[T], first: int, count: int) -> T[]`
- `upload[T] = (b: GpuBuffer[T], xs: T[], at: int = 0)`: xs written into the buffer from element `at` on (before the dispatches and draws that follow)
- `([])[T] = (b: GpuBuffer[T], i: int) -> T`: one element (in GPU memory, outside compute functions: a slow round trip; cpu() reads many). In compute functions, as on the GPU, reading past either end reads the nearest element and writing there does nothing; elsewhere it is an error.
- `([]=)[T] = (b: GpuBuffer[T], i: int, v: T)`
- `words[T] = (b: GpuBuffer[T]) -> GpuBuffer[u32]`: the same memory as 32-bit words, e.g. for atomic_add on a field of DrawArgs: atomic_add(u.arg_words, 1, u32(1)) counts instances (u.arg_words: words(args))

#### Subgroups

- `subgroup_size = () -> int`: In a compute function, the invocations the GPU runs together (a subgroup: 32 of them on NVIDIA, 64 on AMD, fewer on some; 1 on the CPU) combine values without going through memory: subgroup_add(x) is the sum of x over those of them that reach the call together. A program written for any size runs the same everywhere, e.g. one atomic for a subgroup's elements instead of one each: These take numbers and vectors (and, or and xor integers and bools too).



- `draw_indirect_count[U, I] = (sh: Shader, m: Mesh, instances: GpuBuffer[I], args: GpuBuffer[DrawArgs], count: GpuBuffer[u32], params: U, at: int = 0, max_draws: int = -1, count_at: int = 0)`: the same with instance data in a buffer

## Paths

```gdscript
# example: paths
window("Paths", 960, 540)

grid = path_grid(24, 13, 40.0)           # 24 by 13 cells, 40 units across
loop y in [2..11): set_open(grid, 8, y, false)     # two walls
loop y in [0..9): set_open(grid, 16, y, false)
chaser = vec2(60, 260)

update = (dt: f64):
    goal = mouse_pos()
    way = path_step(grid, chaser, goal)  # the next point on the way round the walls
    if distance(way, chaser) > 1.0: chaser += normalize(way - chaser) * 200 * dt

draw = ():
    clear(rgb(0.1, 0.1, 0.13))
    loop y in [0..13):
        loop x in [0..24):
            if not is_open(grid, x, y): rect(x * 40, y * 40, 40, 40, GRAY)
    circle(mouse_pos(), 10, YELLOW)
    circle(chaser, 14, RED)
    text("the red one follows the mouse", vec2(20, 500), 20)
```

Paths over a grid, for enemies finding their way round walls: the grid's cells are open or blocked, and path_step() gives, from anywhere, the next point to walk to on the way to a goal. The steps to each goal are worked out once (a flood over the open cells, eight ways round: diagonally only where both sides are open) and kept until the grid changes.

```gdscript
grid = path_grid(40, 30, 16.0)                  # 40 by 30 cells, 16 units across
set_open(grid, 3, 4, false)                     # a wall there
way = path_step(grid, enemy, player)            # walk toward this
```

Positions are vec2: x and y in a 2D game; on the ground of a 3D one, x and z. origin is where the grid's first cell starts (its corner with the least x and y).

- `struct PathGrid`
  ```gdscript
  struct PathGrid:
      width: int
      height: int
      cell: f64
      origin: vec2
      open: bool[]                # by cell: x + y * width
      fields: {int: int[]} = {}   # (steps to a goal from every cell, by the goal's cell)
  ```
- `path_grid = (width: int, height: int, cell: f64 = 1.0, origin: vec2 = vec2(0, 0)) -> PathGrid`: a grid with every cell open
- `set_open = (g: mut PathGrid, x: int, y: int, open: bool)`
- `is_open = (g: PathGrid, x: int, y: int) -> bool`: whether a cell is open (outside the grid: no)
- `path_cell = (g: PathGrid, p: vec2) -> ivec2`: the cell a point is in (kept within the grid), and the middle of a cell
- `cell_center = (g: PathGrid, c: ivec2) -> vec2`
- `nearest_open = (g: PathGrid, c: ivec2, reach: int = 4) -> ivec2`: the open cell nearest c, looking up to `reach` cells away (c itself when nothing is open)
- `path_distance = (g: mut PathGrid, from: vec2, to: vec2) -> int`: how many steps from one point to another over open cells (-1: there is no way)
- `path_step = (g: mut PathGrid, from: vec2, to: vec2) -> vec2`: Where to head from `from` on the way to `to`: the middle of the next cell, or `to` itself when it is in the same or the next cell (or cannot be reached). Off the open cells (pushed into a corner, or a goal on a crate), the nearest open cell stands in.

```gdscript
    t += dt
    if mouse_pressed(.left):
        sparks.emit(screen_to_world(mouse_pos()), 40, 250, ORANGE)
        shake.add(0.5)
    player.x = 100 + 700 * ease_in_out((sin(t) + 1.0) / 2.0)
    if every(1, 0.5) and overlaps(player, wall): sparks.emit(center(player), 10, 120, RED)
    sparks.update(dt)
    shake.update(dt)
    # (the camera keeps the player in view: it moves once the player is 200 units off center)
    cam = follow(cam, center(player), dt, 4.0, vec2(200, 1000))

draw = ():
    clear(rgb(0.08, 0.08, 0.1))
    camera2d(cam + shake.offset())
    loop x in [0..48):                    # a row of smooth noise
        h = fbm(x * 0.15, t * 0.3)
        rect(x * 20, 300 - 100 * h, 18, 100 * h + 4, rgb(0.3, 0.5, 0.4))
    rect(wall.x, wall.y, wall.w, wall.h, GRAY)
    rect(player.x, player.y, player.w, player.h, if overlaps(player, wall): RED else: CYAN)
    sparks.draw()
    camera2d(vec2(480, 270))
    text("click for sparks (and a shake)", vec2(20, 20), 20)
```

#### Tweens

- `enum TweenMode: once, repeat, pingpong`: once (then it stays at `to`), repeat (from the start again), pingpong (to and back, again and again)
- `struct Tween[T]`
  ```gdscript
  struct Tween[T]:
      from: T
      to: T
      duration: f64
      ease: (f64) -> f64
      mode: TweenMode
      t = 0.0                     # seconds since it started (below 0: still waiting)
  ```
- `tween[T] = (from: T, to: T, duration: f64, ease: (f64) -> f64 = ease_in_out, delay: f64 = 0.0, mode: TweenMode = .once) -> Tween[T]`: a value going from `from` to `to` over `duration` seconds along an easing curve: a number, a position (vec2, vec3) or a color (vec4); delay: seconds before it starts. For example `pop = tween(0.0, 1.0, 0.4, ease_out_back)`, then `pop.update(dt)` each frame and `pop.value()` where it is (grown in 0.4 s, a little past the end, then back).
- `tween = (from: f64, to: f64, duration: f64, ease: (f64) -> f64 = ease_in_out, delay: f64 = 0.0, mode: TweenMode = .once) -> Tween[f64]`: (numbers: tween(0, 10, 0.5) goes through the fractions between)
- `update[T] = (tw: mut Tween[T], dt: f64)`
- `progress[T] = (tw: Tween[T]) -> f64`: where along the curve it is, from 0 to 1 (before the easing)
- `value[T] = (tw: Tween[T]) -> T`
- `done[T] = (tw: Tween[T]) -> bool`: finished (a tween that repeats never is)
- `restart[T] = (tw: mut Tween[T])`: start again from the start
- `retarget[T] = (tw: mut Tween[T], to: T)`: go on from where it is now to a new target, taking duration again

#### The camera: following and shaking

- `follow = (cam: vec2, target: vec2, dt: f64, speed: f64 = 8.0, deadzone: vec2 = vec2(0, 0)) -> vec2`: where a camera that follows target is next: it waits while target stays inside deadzone (half its size, in 2D units, around the camera's center), then catches up smoothly (higher speed: snappier). For camera2d(follow(...)).
- `struct Shake`: A screen shake: add(trauma) on a hit or a blast (0 to 1; more adds up), update(dt) every frame, and move the camera by offset() (in 3D, offset3d(right)): it shakes hard at first, fading as the trauma wears off.

- `update = (s: mut Shake, dt: f64)`
- `offset = (s: Shake) -> vec2`
- `offset3d = (s: Shake, right: vec3, up: vec3 = vec3(0, 1, 0), meters: f64 = 0.25) -> vec3`: the same shake for a 3D camera: up to `meters` along the camera's right and up (add it to where the camera is: `camera3d(eye + shake.offset3d(right), target)`)

## 2D physics

A module (`import physics`): rigid bodies (circles, boxes, convex polygons) that collide, bounce, slide and stack, joined by pins, rods, ropes and springs. Distances are in the screen's units with y down, as in drawing. See [examples/physics.jo](https://github.com/david-andrew/sloppy-lang/blob/master/examples/physics.jo).

```gdscript
# example: physics
import physics

w = physics.World()                                       # gravity: 980 pixels/s² down
w.add_box(vec2(640, 700), vec2(1280, 40), kind = .fixed)  # the floor
crates: physics.Body[]
loop i in [0..5): crates.push(w.add_box(vec2(600 + 8 * i, 600 - 45 * i), vec2(40, 40)))
ball = w.add_circle(vec2(200, 300), 25, bounce = 0.5)
w.push(ball, vec2(600, -200) * w.mass(ball))          # thrown at the stack
lamp = w.add_box(vec2(1000, 220), vec2(30, 60))
w.rod(physics.ground, lamp, vec2(1000, 80), vec2(1000, 190), rope = true)

update = (dt: f64):
    w.step(dt)
    loop c in w.contacts(ball):
        if c.new and c.impulse > 500.0: print("hit, {c.impulse:.0}")

draw = ():
    clear(rgb(0.1, 0.1, 0.14))

```

2D physics: rigid bodies that fall, collide, bounce, slide and stack, held together by pins, rods, ropes, springs, welds, sliders and wheels. `import physics`, then:

```gdscript
w = physics.World()                                     # gravity down, in pixels (as drawing)
floor = w.add_box(vec2(640, 700), vec2(1280, 40), kind = .fixed)
ball = w.add_circle(vec2(640, 100), 24, bounce = 0.6)
update = (dt: f64): w.step(dt)
draw = ():
    circle(w.pos(ball), 24, WHITE)                      # (or physics.draw_debug(w))
```

Bodies are `.dynamic` (moved by forces and collisions), `.fixed` (never move: floors, walls) or `.moving` (moved only by the velocity the game gives them: platforms, doors). Each has a shape: a circle, a box or a polygon (a concave one is cut into convex parts), or several of them held together (`w.add_body(pos, [.circle(vec2(0, -30), 12), physics.box_part(vec2(0, 0), vec2(40, 20))])`). A Body is a handle; ask the world about it (`w.pos(b)`, `w.angle(b)`, `w.velocity(b)`) and change it (`w.push(b, impulse)`).

Units: pixels, seconds, radians. A body's mass is its density times its area / 100 (a 40 x 40 box of density 1 weighs 16; `mass =` gives it outright), an impulse is mass times pixels a second: a contact's `.impulse` divided by the lighter body's mass is the speed it took out. Two bodies touching use the square root of their frictions multiplied, and the larger bounce. A body that would cross more than half its size in a step is swept: it stops at what it would have passed through (no tunneling at any speed). Circles roll on without slowing (there is no rolling resistance): `w.set_damping(b, 1.0)` lets one come to rest.

Joints: `w.pin(a, b, at)` (a hinge at a point), `w.rod(a, b, at_a, at_b)` (a fixed distance; `spring = 4.0` makes it a spring of that many oscillations a second, `rope = true` lets it go slack), `w.weld(a, b, at)` (one piece), `w.slider(a, b, at, axis)` (along a line: a piston, a lift), `w.wheel(car, wheel, at)` (sprung, turning, with a motor), `w.drag(b, at)` and `w.drag_to(j, target)` (pulling a body by a point: the mouse). `physics.ground` is a fixed body to attach things to the world. Two bodies joined by a joint do not collide with each other (the links of a chain overlap where they are pinned).

Each step is the same for the same inputs (a fixed internal step, a fixed order), so a game that steps it with a fixed dt can replay or roll back. Contacts: `w.contacts()` lists the pairs touching after the step (`.new` on the step they met, `.impulse` how hard), `w.separated()` those that stopped touching, and sensors (`sensor = true`) report contacts without colliding: pickups, triggers. Collision layers: bodies a and b collide when a.layer & b.mask and b.layer & a.mask are not 0.

- `enum BodyKind: dynamic, fixed, moving`
- `struct Body`: (a handle: a body's place, and which body has had it: a removed body's handle is not taken for the next one put there)
  ```gdscript
  struct Body:
      id: int
      gen: int
  ```
- `struct Joint`
  ```gdscript
  struct Joint:
      id: int
      gen: int
  ```
- `struct Contact`: a pair of bodies touching after the last step
  ```gdscript
  struct Contact:
      a: Body
      b: Body
      point: vec2
      normal: vec2            # from a toward b
      impulse: f32            # how hard they pushed on each other in the last step (0 for sensors)
      new: bool               # they started touching in the last step
  ```
- `struct Hit`
  ```gdscript
  struct Hit:
      body: Body
      point: vec2
      normal: vec2
      fraction: f32           # how far along the ray, 0 to 1
  ```
- `enum Part: circle(center: vec2, radius: f64), polygon(points: vec2[])`: one of the shapes a body of several is made of (add_body), placed around the body's position
- `box_part = (center: vec2, size: vec2, angle: f64 = 0) -> Part`: a box among a body's parts
- `struct World`
  ```gdscript
  struct World:
      gravity = vec2(0, 980)
      iterations = 8          # solver passes each step (more: stiffer stacks and chains)
      sleep = true            # bodies that have come to rest are left out until something touches them
      substep = 1.0 / 120.0   # the longest internal step, in seconds
      bodies: __PBody[] = [__PBody(kind = .fixed, radius = -1)]
      joints: __PJoint[]
      arbs: __Arb[]
      arb_index: {int: int}
      free: int[]
      events: Contact[]
      ended: (Body, Body)[]
  ```

#### Making bodies

- `add_circle = (w: mut World, pos: vec2, radius: f64, kind: BodyKind = .dynamic, density: f64 = 1.0, friction: f64 = 0.5, bounce: f64 = 0.0, sensor: bool = false, mass: f64 = 0) -> Body`
- `add_box = (w: mut World, pos: vec2, size: vec2, angle: f64 = 0, kind: BodyKind = .dynamic, density: f64 = 1.0, friction: f64 = 0.5, bounce: f64 = 0.0, sensor: bool = false, mass: f64 = 0) -> Body`
- `add_polygon = (w: mut World, pos: vec2, points: vec2[], angle: f64 = 0, kind: BodyKind = .dynamic, density: f64 = 1.0, friction: f64 = 0.5, bounce: f64 = 0.0, sensor: bool = false, mass: f64 = 0) -> Body`: points around pos, in order: a concave polygon is cut into convex parts (points not in order, or crossing themselves: their convex hull)
- `add_body = (w: mut World, pos: vec2, parts: Part[], angle: f64 = 0, kind: BodyKind = .dynamic, density: f64 = 1.0, friction: f64 = 0.5, bounce: f64 = 0.0, sensor: bool = false, mass: f64 = 0) -> Body`: a body made of several shapes, held together as one: `.circle(center, radius)`, `.polygon(points)` and `box_part(center, size)`, placed around pos (turned by angle). Its frame is then at its center of mass, not at pos: w.pos(b), to_world and to_local use that point (`w.to_world(b, p - (w.pos(b) - pos))` places p as given around pos, before it turns)
- `set_mass = (w: mut World, b: Body, m: f64)`: give a dynamic body another mass (its turning inertia changes with it)
- `remove = (w: mut World, b: Body)`: take b out of the world (and the joints it is in); its handle then means nothing (a handle used after this panics; removing twice does nothing)
- `remove = (w: mut World, j: Joint)`
- `joint_alive = (w: World, j: Joint) -> bool`: the joint is still there (not removed, nor one of its bodies)

#### Asking and changing

- `pos = (w: World, b: Body) -> vec2`
- `angle = (w: World, b: Body) -> f64`
- `velocity = (w: World, b: Body) -> vec2`
- `spin = (w: World, b: Body) -> f64`
- `mass = (w: World, b: Body) -> f64`
- `kind = (w: World, b: Body) -> BodyKind`
- `alive = (w: World, b: Body) -> bool`
- `tag = (w: World, b: Body) -> int`: a number of the game's own, kept with the body (what it is: a coin, an enemy's index...)
- `set_tag = (w: mut World, b: Body, t: int)`
- `bodies = (w: World) -> Body[]`: every body there is (not ground)
- `radius = (w: World, b: Body) -> f64`: a circle's radius (0 for a polygon)
- `to_world = (w: World, b: Body, local: vec2) -> vec2`: a point of the body, in the world (from the body's own frame), and back
- `to_local = (w: World, b: Body, p: vec2) -> vec2`
- `set_pos = (w: mut World, b: Body, p: vec2)`
- `set_angle = (w: mut World, b: Body, a: f64)`
- `set_velocity = (w: mut World, b: Body, v: vec2)`
- `set_spin = (w: mut World, b: Body, s: f64)`
- `sleeping = (w: World, b: Body) -> bool`: it is asleep: at rest with all it touches, left out of each step until something touches it
- `set_damping = (w: mut World, b: Body, d: f64)`: slowing down by itself (as through air or water): the share of its speed lost each second
- `set_fixed_rotation = (w: mut World, b: Body, on: bool)`: it never turns (a character's body)
- `set_friction = (w: mut World, b: Body, f: f64)`
- `set_bounce = (w: mut World, b: Body, f: f64)`
- `set_layers = (w: mut World, b: Body, layer: int, mask: int = -1)`
- `push = (w: mut World, b: Body, impulse: vec2)`: a sudden change of motion (a jump, a hit), at a point of the world (its center: no turning)
- `push = (w: mut World, b: Body, impulse: vec2, at: vec2)`
- `apply_force = (w: mut World, b: Body, f: vec2)`: a steady force for the next step (thrust, wind): give it every frame it acts
- `apply_torque = (w: mut World, b: Body, t: f64)`

#### Joints

- `pin = (w: mut World, a: Body, b: Body, at: vec2, lower: f64 = -1e9, upper: f64 = 1e9, motor_speed: f64 = 0, max_torque: f64 = 0) -> Joint`: a hinge: a and b turn about the point at (in the world, now) lower, upper: how far b may turn against a (radians, from how they are now); motor_speed: b turned against a at that many radians a second, with up to max_torque (0: no motor)
- `weld = (w: mut World, a: Body, b: Body, at: vec2) -> Joint`: a and b held together at at, as one: neither moves or turns against the other (a joint that can be undone, unlike one body of both shapes)
- `slider = (w: mut World, a: Body, b: Body, at: vec2, axis: vec2, lower: f64 = -1e9, upper: f64 = 1e9, motor_speed: f64 = 0, max_force: f64 = 0) -> Joint`: b slides against a along a line through at in the direction axis (in the world, now) and does not turn against it: a piston, a sliding door, a lift. lower, upper: how far b may go along the line from where it is now; motor_speed: driven along it at that many units a second, with up to max_force (0: no motor)
- `wheel = (w: mut World, a: Body, b: Body, at: vec2, axis: vec2 = vec2(0, 1), spring: f64 = 4, damping: f64 = 0.7, motor_speed: f64 = 0, max_torque: f64 = 0) -> Joint`: a car's wheel: b (the wheel) held to a (the car) at at, free to move only along axis (the suspension, in the world, now: up and down by default) on a spring of that many oscillations a second (damping: 0 bounces on, 1 settles at once), and free to turn; motor_speed turns it at that many radians a second, with up to max_torque (0: it rolls freely)
- `joint_translation = (w: World, j: Joint) -> f64`: how far b is along a slider's or wheel's line from where it started
- `set_motor = (w: mut World, j: Joint, speed: f64, max_torque: f64)`: change a pin's or wheel's motor (b turns against a at speed radians a second, with up to max_torque), or a slider's (b moves along it at speed units a second, with up to max_torque as a force); 0: no motor
- `set_limits = (w: mut World, j: Joint, lower: f64, upper: f64)`: change how far a pin lets b turn against a (from lower to upper radians), or a slider lets it move along its line
- `joint_angle = (w: World, j: Joint) -> f64`: how far b has turned against a since the joint was made, in radians
- `rod = (w: mut World, a: Body, b: Body, at_a: vec2, at_b: vec2, spring: f64 = 0, damping: f64 = 0.5, rope: bool = false) -> Joint`: the points at_a of a and at_b of b (in the world, now) kept as far apart as they are; with spring > 0 a spring of that many oscillations a second (damping: 0 bounces on, 1 settles at once); with rope, only as far apart at most
- `drag = (w: mut World, b: Body, at: vec2, strength: f64 = 1000) -> Joint`: pulls the point at of b toward a target (drag_to), as a stiff spring: grabbing with the mouse
- `drag_to = (w: mut World, j: Joint, target: vec2)`
- `ends = (w: World, j: Joint) -> (vec2, vec2)`: where a joint's two ends are now: on a and on b (a rope or rod is drawn between them; a pin's are its hinge as each body has it, one point unless it is stretched; a drag's: its target, and the point it pulls)
- `set_length = (w: mut World, j: Joint, l: f64)`: set a rod's length (a winch)

#### Stepping

- `step = (w: mut World, dt: f64)`: move the world on by dt seconds (in steps of at most w.substep)
- `contacts = (w: World) -> Contact[]`: the pairs touching after the last step
- `separated = (w: World) -> (Body, Body)[]`: the pairs that touched before the last step and no longer do (a ball leaving a trigger, a foot leaving the ground)
- `contacts = (w: World, b: Body) -> Contact[]`: those that b is one of (each turned so that .a is b)

#### Queries

- `raycast = (w: World, a: vec2, b: vec2, mask: int = -1) -> Hit?`: the first body a ray from a to b meets (only those whose layer & mask is not 0)

#### Overlaps

- `overlap_circle = (w: World, center: vec2, radius: f64, mask: int = -1) -> Body[]`: the bodies (sensors too) a circle or a box overlaps: what an explosion reaches, the zones something stands in (bodies_at(p): those at a point)
- `overlap_box = (w: World, center: vec2, size: vec2, angle: f64 = 0, mask: int = -1) -> Body[]`
- `circle_cast = (w: World, a: vec2, b: vec2, r: f64, mask: int = -1) -> Hit?`
- `bodies_at = (w: World, p: vec2) -> Body[]`: the bodies at the point p (the topmost first: the last made)
- `outline = (w: World, b: Body) -> vec2[]`: a body's outline in the world (a circle's as 24 points; a concave polygon as it was given; a body of parts from add_body: around all of them, so draw those with outlines)
- `outlines = (w: World, b: Body) -> vec2[][]`: the outline of each of a body's parts (one, for a body of one shape)
- `draw_debug = (w: World, thickness: f64 = 2)`: every body's outline and every joint, for seeing what the physics does

3D physics: rigid bodies (spheres, boxes, capsules) that fall, collide, slide, roll and stack, a level's triangles to stand on, joints, rays, and a character controller for walking. `import physics3d`, then:

```gdscript
w = physics3d.World()                                   # meters, y up, gravity 9.81 down
w.add_box(vec3(0, -0.5, 0), vec3(40, 1, 40), kind = .fixed)        # (a size: full lengths)
crate = w.add_box(vec3(0, 3, 0), vec3(1, 1, 1))
ball = w.add_sphere(vec3(0.3, 6, 0), 0.5, bounce = 0.4)
update = (dt: f64): w.step(dt)
draw = (): draw_mesh(cube, w.transform(crate))         # (position and turn, as a mat4)
```

Masses come from sizes and `density` (kilograms per cubic meter: 1000 is water's, so a ball of radius 0.5 weighs 524 kg), or are given: `w.add_sphere(pos, 0.5, mass = 1)`, `w.set_mass(b, 2)`. Bodies are `.dynamic`, `.fixed` or `.moving` (moved only by the velocity the game gives them), with one shape each; `w.add_mesh(triangles)` adds fixed triangles (a level, from a model: physics3d.triangles(model_data); a terrain_mesh: physics3d.terrain_triangles). Joints: `w.ball(a, b, at)` (a ball and socket), `w.hinge(a, b, at, axis)`, `w.rod(a, b, at_a, at_b)` (a distance, or a spring, or a rope). Rays: `w.raycast`. A character: `w.character(pos, radius, height)` and `w.walk(c, velocity, dt)`, a capsule that walks up slopes and steps, slides down steeper ones, and is pushed by nothing but the level. Contacts: `w.contacts(b)` after a step, each with `.new` on the step they met; a sensor (`sensor = true`: a pickup, a trigger zone) collides with nothing but is in them too. As in 2D, stepping is the same for the same inputs (for replays and rollback). A small, fast body can pass through a thin wall in one step (there is no continuous collision yet): for bullets, use w.raycast from where they were to where they are.

#### Making bodies

- `add_sphere = (w: mut World, pos: vec3, radius: f64, kind: BodyKind = .dynamic, density: f64 = 1000, friction: f64 = 0.5, bounce: f64 = 0.0, sensor: bool = false, mass: f64 = 0) -> Body`

#### Rays

- `raycast = (w: World, a: vec3, b: vec3, mask: int = -1) -> Hit?`: the first body a ray from a to b meets (only those whose layer & mask is not 0; sensors are passed through)
- `sphere_cast = (w: World, a: vec3, b: vec3, r: f64, mask: int = -1) -> Hit?`: the first body a ball of radius r, moved from a to b, would touch: the hit's point is where it touches, and fraction how far along the ball's center is then (a thick ray: bullets that are not points, a camera kept out of walls, what is under a character's feet)

#### A character

- `struct Character`: A capsule that walks: it stands on what it can (slopes up to max_slope, steps up to step high), slides down steeper slopes, stops at walls, and keeps to the ground going down slopes and steps. It is not a body: the level and fixed and moving bodies stop it, and it shoves dynamic ones out of its way (as hard as its mass against theirs, times push), which stops it as much as they do not give way.
  ```gdscript
  struct Character:
      feet: vec3                      # the bottom of the capsule
      radius = 0.3
      height = 1.8
      velocity: vec3                  # as it moves (falling builds up here)
      on_ground = false
      ground_normal = vec3(0, 1, 0)
      standing_on = Body(0, 0)        # the body it stands on (a moving platform carries it)
      max_slope = 50deg
      step = 0.35
      layer = 1
      mask = -1
      mass = 80.0                     # (kilograms: what it shoves)
      push = 1.0
  ```
- `character = (w: World, feet: vec3, radius: f64 = 0.3, height: f64 = 1.8) -> Character`
- `walk = (w: mut World, c: mut Character, move: vec3, dt: f64, jump: f64 = 0)`: move c for dt seconds, at the velocity `move` along the ground (its y is not used), and jumping at `jump` meters a second when on the ground and jump > 0

## Networking

A module (`import net`): messages between programs over WebSockets, so a native build and a web page can play together (a server is a native program; a web page connects to one: [examples/netpong](https://github.com/david-andrew/sloppy-lang/tree/master/examples/netpong)), and UDP datagrams between native programs.

```gdscript
# example: networking
import net

window("Chat", 960, 540)

# HOST=1: a server here; else a client of localhost (or ?join=address in a web page)
hosting = env("HOST") != none
if hosting: net.listen(4000)
else: net.connect(env("JOIN") ?? "localhost", 4000)
said: str[]

update = (dt: f64):
    loop e in net.receive():
        if e.kind == .joined: said.push("({e.peer} is here)")
        else if e.kind == .left: said.push("({e.peer} left)")
        else:
            said.push("{e.peer}: {e.text}")
            if hosting: net.send_all(e.data)       # (a server passes each message on)
    if key_pressed(.space): net.send_all("hello at {elapsed():.1} s")

draw = ():
    clear(rgb(0.08, 0.09, 0.12))
    text("Space: say hello", vec2(20, 20), 22)
    loop i in 0.. and line in said[max(said.len() - 18, 0)..]: text(line, vec2(20, 70 + 24 * i), 20)
```

Networking: messages between programs, over WebSockets, so that the same game reaches others from a native build and from a web page. `import net`, then:

```gdscript
net.listen(4000)                        # a server: others connect to this machine's port 4000
p = net.connect("192.168.1.20", 4000)   # a client: a peer (it connects in the background)
loop e in net.receive():                # what happened since the last call (every frame)
    if e.kind == .joined: ...           # a peer connected (to a server, or the server, to a client)
    if e.kind == .message: print(e.text)
    if e.kind == .left: ...             # it went away (or could not be reached)
net.send(p, "hello")                    # a str or u8[]; net.send_all(...) to every peer
```

Messages arrive whole and in order (WebSockets over TCP). A web page can only connect, not listen: the server is a native program (a game that hosts, or a small server of its own). A page served over https can only reach a wss:// server (TLS: put a proxy that has a certificate, such as Caddy, in front of the server); net.connect("wss://game.example.com") takes a URL as well.

- `enum NetKind: joined, message, left`
- `struct NetEvent`
  ```gdscript
  struct NetEvent:
      kind: NetKind
      peer: int
      data: u8[]              # a message's bytes ...
      text = ""               # ... and as text
  ```

#### The peers

- `listen = (port: int) -> bool`: start a server on port (native programs); false if the port cannot be had
- `connect = (host: str, port: int = 0) -> int`: connect to a server: a peer, connecting in the background (joined or left arrive by receive); host is a name or address and port its port, or host is a ws:// or wss:// URL (port then unused)
- `send = (peer: int, msg: u8[])`: send a message to a peer (nothing if it is not connected, or has gone): text goes as a text message (a string to a page's WebSocket), bytes as a binary one
- `send = (peer: int, msg: str)`
- `send_all = (msg: u8[])`: send a message to every connected peer
- `send_all = (msg: str)`
- `peers = () -> int[]`: the peers connected now
- `close = (peer: int)`: end a connection (a left event follows)
- `receive = () -> NetEvent[]`: what happened since the last call: peers joining and leaving, and their messages, in order
- `receive = (only: int[]) -> NetEvent[]`: the same, for the given peers only (the others' events wait for another call): parts of a program that each have peers of their own, as a game hosting a relay and playing through it
- `receive_server = () -> NetEvent[]`: the same, for the peers that connected to this program's server (listen) only

#### UDP (native programs)

- `struct Datagram`
  ```gdscript
  struct Datagram:
      host: str               # where it came from: an address, "1.2.3.4"
      port: int
      data: u8[]
  ```
- `udp = (port: int = 0) -> int`: a UDP socket on port (0: one the system picks), or -1 (in use, or in a web page)
- `udp_send = (sock: int, host: str, port: int, data: u8[]) -> bool`: false if host is not known or it could not be sent (a datagram may also be lost on the way)
- `udp_send = (sock: int, host: str, port: int, text: str) -> bool`
- `udp_receive = (sock: int) -> Datagram[]`: the datagrams that have arrived since the last call
- `udp_close = (sock: int)`

#### TCP: a stream of bytes to one other program

- `tcp_connect = (host: str, port: int, timeout: f64 = 5.0) -> int`: a connection to host's port, waiting up to `timeout` seconds for it; -1 if it cannot be made
- `tcp_listen = (port: int) -> int`: a server on port: connections come from tcp_accept; -1 if the port cannot be had
- `tcp_accept = (server: int, wait: f64 = 0.0) -> int`: a connection made to the server (waiting up to `wait` seconds for one), or -1 if none came
- `tcp_send = (c: int, data: u8[]) -> bool`: all of data sent (waiting while the other side is slow to take it); false if the connection has failed or closed
- `tcp_send = (c: int, text: str) -> bool`
- `tcp_receive = (c: int, wait: f64 = 0.0) -> u8[]`: the bytes that have arrived (waiting up to `wait` seconds for the first); empty when none has (or the connection has ended: tcp_closed says)
- `tcp_closed = (c: int) -> bool`: the other side has closed the connection (or it failed), and everything sent has been received
- `tcp_close = (c: int)`

## Netplay

A module (`import netplay`): players on different machines in one game. With rollback (`session`), only inputs travel, and a late one is made up for by playing the last ticks again; with a server (`server`, `client`), the server runs the game and clients predict their own moves and draw others a little in the past. Sloppy's math is its own (no system math library, no fused multiply-add), so a tick comes out the same on Linux, Windows, macOS and the web. See [examples/duel](https://github.com/david-andrew/sloppy-lang/tree/master/examples/duel) and [examples/arena](https://github.com/david-andrew/sloppy-lang/tree/master/examples/arena), and [playing over a network](MULTIPLAYER.md) for choosing between them.

```gdscript
# example: netplay
# (two machines in one program, over a simulated network with 150 ms latency: the top half is what
# player 1's machine shows, the bottom half player 2's; steer player 1 with the arrows)
import netplay

struct Pad:
    x = 0
struct Game:
    xs: f32[] = [400, 800]

tick = (g: Game, pads: Pad[]) -> Game:
    let g = g
    loop i in [0..2): g.xs[i] = clamp(g.xs[i] + 6 * pads[i].x, 20, 1260)
    g

a = netplay.session(Game(), tick, players = 2, me = 0)
b = netplay.session(Game(), tick, players = 2, me = 1)
link = netplay.Link(latency = 0.15)
now = 0.0

update = (dt: f64):
    now += 1.0 / 60.0
    a.play(Pad(int(round(input_axis().x))))
    b.play(Pad(int(sign(sin(now * 1.3)))))                 # (player 2 plays by itself)
    loop o in a.outgoing(): link.send(o.0, o.1, now)
    loop o in b.outgoing(): link.send(o.0, o.1, now)
    loop d in link.deliver(now):
        if d.0 == 0: a.receive(d.1)
        else: b.receive(d.1)

draw = ():
    clear(rgb(0.08, 0.09, 0.12))
    loop half in 0.. and g in [a.state, b.state]:
        y = 180 + 360 * half
        circle(vec2(g.xs[0], y), 24, rgb(0.35, 0.7, 1.0))
        circle(vec2(g.xs[1], y), 24, rgb(1.0, 0.6, 0.3))
    line(vec2(0, 360), vec2(1280, 360), 2, gray(0.3))
    text("rollbacks: {a.rollbacks} and {b.rollbacks}", vec2(20, 20), 22, gray(0.6))
```

- `struct Session[S, I]`
  ```gdscript
  struct Session[S, I]:
      step: (S, I[]) -> S
      players: int
      me: int
      delay = 2
      max_ahead = 10                  # (no more than __NP_HIST / 2)
      tick = 0                        # the tick state is at
      state: S
      waiting = false                 # play could not move on (too far ahead of someone's inputs)
      rollbacks = 0                   # how many times a tick was played again, so far
      longest_rollback = 0
      desync = -1                     # the first tick at which two machines' games differed (-1: none)
      problem = ""                    # what is wrong, said once on stderr too: packets that cannot be
  ```
- `session[S, I] = (start: S, step: (S, I[]) -> S, players: int, me: int, delay: int = 2) -> Session[S, I]`: a session of `players` players, this machine's being player `me` (from 0)
- `confirmed[S, I] = (s: Session[S, I]) -> int`: ticks below this have every player's input: they will not change again (some may not have been played here yet: those from s.tick on)
- `silent[S, I] = (s: Session[S, I], p: int) -> f64`: player p has not been heard from for this many seconds
- `ping[S, I] = (s: Session[S, I], p: int) -> f64`: the round trip to player p and back, in milliseconds (smoothed; 0 before it is known)
- `play[S, I] = (s: mut Session[S, I], input: I)`: this frame's input from this machine's player; the game moves on a tick (unless waiting)
- `outgoing[S, I] = (s: mut Session[S, I]) -> (int, u8[])[]`: what to send to whom since the last call: (player, bytes) (without s.udp)
- `receive[S, I] = (s: mut Session[S, I], data: u8[])`: bytes that arrived from another player (the packet says which)
- `lag[S, I] = (s: mut Session[S, I], ms: f64, jitter_ms: f64 = 0, loss: f64 = 0)`: simulate a slow network on what this session sends: ms more latency, up to jitter_ms more at random, and a share of packets lost (0 to 1)

#### Over UDP (native programs)

- `udp[S, I] = (s: mut Session[S, I], port: int, addrs: (str, int)[])`: play over UDP: this machine listens on port, and each player p is at addrs[p] (this one's own entry is not used)

#### Through a relay (web pages too)

- `join_relay[S, I] = (s: mut Session[S, I], host: str, port: int, room: str, stun: str = "stun:stun.l.google.com:19302")`: play through the relay at host and port (or a ws:// or wss:// URL), with the players who name the same room
- `direct[S, I] = (s: Session[S, I], p: int) -> bool`: player p's packets come and go straight (WebRTC between web pages), not through the relay
- `relay = (port: int)`: a relay on port: call it every frame (in a game that hosts others), or relay_forever
- `relay_forever = (port: int)`: a program that is only a relay

#### A simulated network, for trying netplay in one program

- `struct Link`: packets between numbered ends, each arriving after latency (plus up to jitter at random), some lost; time is the caller's (seconds), so a test runs the same every time
  ```gdscript
  struct Link:
      latency = 0.05
      jitter = 0.0
      loss = 0.0
      seed: u64 = 1
  ```
- `send = (l: mut Link, to: int, data: u8[], now: f64)`
- `deliver = (l: mut Link, now: f64) -> (int, u8[])[]`: what has arrived by now: (to, data), in the order it arrives

#### Client and server

- `struct Server[W, I]`
  ```gdscript
  struct Server[W, I]:
      world: W
      apply: (W, int, I, W) -> W
      step: (W) -> W
      tick = 0
      send_every = 2                  # (30 worlds a second)
      joined: int[]                   # the players who came, and went, in the last update
      left: int[]
  ```
- `server[W, I] = (world: W, apply: (W, int, I, W) -> W, step: (W) -> W) -> Server[W, I]`
- `join[W, I] = (s: mut Server[W, I], player: int)`: a player connected (as the player number, any int); a player left
- `leave[W, I] = (s: mut Server[W, I], player: int)`
- `receive[W, I] = (s: mut Server[W, I], player: int, data: u8[])`: bytes from a player
- `outgoing[W, I] = (s: mut Server[W, I]) -> (int, u8[])[]`: what to send to whom since the last call (without listen)
- `listen[W, I] = (s: mut Server[W, I], port: int)`: serve over WebSockets on port: native and web clients connect (players are net's peers)
- `update[W, I] = (s: mut Server[W, I])`: one tick: each player's next input applied, the rest of the tick, and the world sent out
- `world_at[W, I] = (s: Server[W, I], tick: int) -> W`: the world as it was at an earlier tick (the latest kept, if that one is gone)
- `struct Client[W, I]`
  ```gdscript
  struct Client[W, I]:
      apply: (W, int, I, W) -> W
      state: W                        # the latest world from the server, with this player's newer inputs applied
      server: W                       # the latest world from the server, as it sent it
      me = -1                         # this player's number (once the server has said)
      server_tick = -1                # the tick of server
      interpolation = 6               # how far in the past others are drawn (view), in ticks
      ping = 0.0                      # milliseconds from an input sent to the world that answers it (smoothed)
      problem = ""                    # what is wrong, said once on stderr too: could not connect, the
  ```
- `client[W, I] = (start: W, apply: (W, int, I, W) -> W) -> Client[W, I]`
- `connect[W, I] = (c: mut Client[W, I], host: str, port: int)`
- `connected[W, I] = (c: Client[W, I]) -> bool`: connected, and the server has sent a world (and is still heard from)
- `play[W, I] = (c: mut Client[W, I], input: I)`: this tick's input: applied here at once (prediction) and sent
- `receive[W, I] = (c: mut Client[W, I], data: u8[])`: bytes from the server
- `outgoing[W, I] = (c: mut Client[W, I]) -> u8[][]`: what to send since the last call (without connect)
- `view_tick[W, I] = (c: Client[W, I]) -> f64`: the server's tick being drawn for the others: some ticks in the past (fractional)
- `view[W, I] = (c: Client[W, I]) -> (W, W, f32)`: the two worlds around view_tick and how far between them (0 to 1): draw the others at mix(a's, b's, f)
